# Massenaktionen Seite — CSS Dokumentation

Die **„Massedaten-Aktionen"** Seite (`Section 93`) ist über den dritten Tab in der Leads-Navigation erreichbar. Sie zeigt eine Tabelle aller durchgeführten Massenaktionen mit Filter-Bar (Datum, Status, Aktion, Benutzer) und Pagination.

**Scope:** `#bulkActionsList`

## Dropdown Options (teleportiert — global)

NaïveUI teleportiert alle Filter-Dropdowns zu `<body>` — kein `#bulkActionsList` Scope möglich. GHL setzt `--n-option-color-active` als Inline-Style auf den Menu-Container. Fix: CSS-Variable direkt auf `.hr-base-select-menu` überschreiben + Hex-Fallback:

```css
/* CSS-Variable auf Menu Container überschreiben */
.hr-base-select-menu {
  --n-option-color-active:         #fdf2f3 !important;
  --n-option-color-active-pending: #f5e4e6 !important;
}

/* Selected State — Hex-Fallback (wine-lt = #fdf2f3) */
body .hr-base-select-option.hr-base-select-option--selected,
.hr-base-select-menu .hr-base-select-option.hr-base-select-option--selected {
  background-color: #fdf2f3 !important;
  color: var(--wine-2) !important;
}

/* Hover / Pending */
.hr-base-select-option--pending {
  background-color: var(--wine-lt) !important;
  color: var(--wine-2) !important;
}

/* Checkmark */
.hr-base-select-option--selected .hr-base-select-option__check svg path {
  fill: var(--wine-2) !important;
}
```

> ⚠️ **Nuclear Fix notwendig** — GHL setzt `--n-option-color-active` mit `!important` als Inline-Style auf den `.hr-base-select-menu` Container. `body` + doppelte Klassen-Kombination ist notwendig um die Spezifität zu übertreffen. Hex-Wert `#fdf2f3` entspricht `var(--wine-lt)` und greift auch wenn die CSS-Variable nicht aufgelöst wird.

## Besonderheiten

- **Status Badges bleiben semantisch** — `Vollständig` = grün, `In Bearbeitung` = gelb, `Fehlgeschlagen` = rot. Diese Bedeutungen dürfen nicht durch Wine ersetzt werden.
- **Avatar-Farben bleiben GHL-generiert** — Benutzer-Avatare erhalten benutzerspezifische Hintergrundfarben von GHL. Nur `.hr-avatar__text` (Initialen) und leere Avatare werden auf Wine umgestellt.
- **Teleportierte Dropdowns** — Alle drei Filter-Selects (Status, Aktionen, Benutzer) teleportieren ihr Menü zu `<body>`. Der globale Override via `.hr-base-select-menu` gilt damit für **alle** NaïveUI-Dropdowns auf der Seite.
- **Statistiken-Icon** — Das Balkendiagramm-Icon pro Zeile (`⊟`) öffnet Detailstatistiken. Hover → `var(--wine-2)`.
- **Kebab-Menü** — Das 3-Punkte-Icon pro Zeile öffnet Aktionen (z.B. Löschen). Hover → `var(--wine-2)`.
