# Massedaten bearbeiten Drawer — CSS Dokumentation

Der **„Massedaten bearbeiten"** Drawer (`Section 88`) öffnet sich nach dem Auswählen mehrerer Einträge in der Listenansicht. Er hat zwei Zustände die dynamisch wechseln:

| State | Beschreibung | Trigger |
|---|---|---|
| **State A · Feld-Auswahl** | Suchfeld + Collapse-Liste aller verfügbaren Felder | Initial beim Öffnen |
| **State B · Feld-Bearbeitung** | Formular-Zeilen mit Inputs + Delete + Add-Field Button | Nach Klick auf ein Feld |

**Scope:** `.hr-drawer-content.hl-drawer-content`

---

## Besonderheiten

- **State A vs. State B** — beide Zustände teilen denselben Drawer-Scope. State A zeigt die Feldliste (`.field` + `.hr-collapse`), State B zeigt die Formular-Zeilen (`.grid.field-layout`). GHL blendet jeweils den anderen State aus — kein Scope-Wechsel notwendig.
- **Delete-Button nutzt `danger`** — `#delete-button` ist eine destruktive Aktion, daher Wine-Logik ausgenommen. Hover zeigt `var(--danger)` mit 6% Rot-Hintergrund.
- **Disabled Felder** — `.field-disabled` zeigt Felder die nicht editiert werden können (z.B. abhängige Pflichtfelder). Opacity-Behandlung statt Wine-Hover.
- **`#positive-btn` background-image-Trick** nicht notwendig — direktes `background-color` greift hier da der Button kein NaïveUI Primary-Type mit Gradient-Override ist.
