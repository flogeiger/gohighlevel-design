# CRM Opportunities — Kanban & Listenansicht

Diese Seite dokumentiert alle CSS-Sections für die Opportunities-Ansicht (`#OpportunitiesList`) im SalonQueen GHL Whitelabel. Erreichbar über **Leads → Leads**.

### Pipeline Dropdown (NaïveUI `hr-base-selection`)
NaïveUI injiziert Borders über CSS-Variablen inline — direkt überschreiben:
```css
#OpportunitiesList .hr-base-selection {
  --n-border-hover:      1px solid var(--wine) !important;
  --n-border-active:     1px solid var(--wine) !important;
  --n-box-shadow-focus:  0 0 0 2px var(--wine-ring) !important;
  --n-caret-color:       var(--wine) !important;
}
#OpportunitiesList .hr-base-selection__border {
  border: 1px solid var(--line-hard) !important;
}
```

### View Toggle Icons
```css
#OpportunitiesList #kanban-toggle-btn.active,
#OpportunitiesList #list-view-toggle-btn.active {
  color: var(--wine-2) !important;
  background-color: var(--wine-lt) !important;
}
```

### Ghost Buttons (Import, Sort By, Filter)
```css
#OpportunitiesList .hr-button--default-type {
  border: 1px solid var(--line-hard) !important;
  color: var(--ink-2) !important;
  --n-border-hover:     1px solid var(--wine) !important;
  --n-text-color-hover: var(--wine-2) !important;
}
```

### Primary Buttons (Hinzufügen Gelegenheit)
NaïveUI setzt `background-color` über `--n-color-hover` — `background-image` hat im Background-Shorthand immer höhere Priorität und gewinnt:
```css
#OpportunitiesList .hr-button--primary-type,
#OpportunitiesList .hr-button--primary-type:hover {
  background-image: linear-gradient(var(--wine), var(--wine)) !important;
}
#OpportunitiesList .hr-button--primary-type:hover {
  background-image: linear-gradient(var(--wine-2), var(--wine-2)) !important;
}
```

### Views Bar (Alle / Liste Tabs)
Der aktive Tab-Indikator wird über `::after` gezeichnet — kein `border-bottom`:
```css
#OpportunitiesList #views-bar .view.active {
  color: var(--wine-2) !important;
  border-bottom: none !important;
}
#OpportunitiesList #views-bar .view.active::after {
  background-color: var(--wine) !important;
}
```

### Dropdown Options (global, kein Scope)
```css

.hr-base-select-option:hover,
```

> ⚠️ Diese Selektoren haben **keinen `#OpportunitiesList` Scope** — NaïveUI teleportiert Dropdown-Menüs direkt zu `<body>`.

![Opportunities List View Screenshot](/opportunities-listview-screenshot.png)

```css

  width: 16px !important;
  height: 16px !important;

}
```

## Besonderheiten

- **Stage-Header Farbe** — die farbige Oberkante der Kanban-Stage-Karten kommt von GHL Inline-Style (`--6a71572e`) und wird bewusst **nicht** überschrieben.
- **`hr-base-selection-input`** — NaïveUI injiziert beim Focus einen weißen/blauen Browser-Hintergrund. Fix: `background: transparent`, `outline: none`, `-webkit-appearance: none`.
- **Tabulator ≠ NaïveUI** — die Listenansicht verwendet Tabulator.js mit eigenen Klassen (`.tabulator-*`), keine `hr-`-Prefix Komponenten.
- **Inline-Farben im Empty State** — Tabulator rendert `style="color:#101828"` direkt auf DOM-Elemente. Fix via Attribut-Selektor `[style*="color:#101828"]`.
