# Pipeline-Einstellungen Seite — CSS Dokumentation

Die **„Pipelines"** Seite (`Section 89`) ist über den Tab „Pipelines" in der Leads-Navigation erreichbar. Sie zeigt eine Tabelle aller vorhandenen Pipelines mit Suche, Pagination und einem „+ Pipeline Erstellen" Button.

**Scope:** `#pipeline-page`

### „+ Pipeline Erstellen" Button (`#primary-blue`)
GHL nutzt die ID `#primary-blue` für diesen Primary-Button — direktes `background-color` Override:
```css
#pipeline-page #primary-blue {
  background-color: var(--wine) !important;
  border-color: var(--wine) !important;
  color: #ffffff !important;
}
#pipeline-page #primary-blue:hover {
  background-color: var(--wine-2) !important;
  border-color: var(--wine-2) !important;
}
/* .hr-button__border ist ein separates Div */
#pipeline-page #primary-blue .hr-button__border       { border-color: var(--wine) !important; }
#pipeline-page #primary-blue:hover .hr-button__border  { border-color: var(--wine-2) !important; }
```

## Besonderheiten

- **`#primary-blue`** — GHL nutzt diese generische ID für den „Pipeline Erstellen" Button. Direktes `background-color` Override notwendig da kein NaïveUI Primary-Typ verwendet wird.
- **Header Icons als `<img>`** — Die Icons in der Tabellenkopfzeile (Pipeline-Name, Anzahl, Datum, Aktivitäten) sind als `<img>` gerendert. CSS `filter` konvertiert zu einem Wine-nahen Farbton.
- **Pagination aktive Seite** — GHL setzt keinen Wine-Farbton für die aktive Seite. Override via `.hr-pagination-item__active button` mit `wine-lt` Background und `wine-2` Text.
- **Kebab-Button ID** — `#pipeline-actions-button` erscheint pro Tabellenzeile. Die ID ist nicht unique im DOM — CSS-Override greift trotzdem auf alle Instanzen.
