# Zu Vorlagen hochladen Modal — CSS Dokumentation

Das **„Zu Dashboards und Reporting-Vorlagen hochladen"** Modal (`Section 104`) öffnet sich über das Kebab-Menü eines Dashboards. Es ermöglicht das Hochladen eines Dashboards als wiederverwendbare Vorlage mit Name und Kategorie.

**Scope:** `#create-template-modal`

> ⚠️ Dieses Modal verwendet den **`hr-`** Komponenten-Präfix statt `n-` (NaïveUI). Selektoren wie `.hr-button__border`, `.hr-input`, `.hr-base-selection` etc. gelten statt der üblichen NaïveUI-Klassen.

## Besonderheiten

- **`hr-` Präfix statt `n-`** — Dieses Modal ist eine andere GHL-Komponente die nicht NaïveUI verwendet, sondern eigene `hr-`-Klassen. Selektoren wie `.hr-button__border`, `.hr-base-selection`, `.hr-input` etc. sind hier maßgeblich.
- **Hinweis Alert Farbe** — GHL setzt `border-color` und `background-color` für den Warning-Alert auf Orange. Beide werden direkt auf wine-Töne überschrieben — kein `--n-*` Variablen-Override möglich.
- **Upload Icon Avatar** — `.hr-avatar` hat eine GHL-generierte Hintergrundfarbe. `background-color: var(--wine-lt)` überschreibt direkt.
- **Box-Shadow 4px** — Dieses Modal nutzt `0 0 0 4px` Focus-Ring statt dem üblichen `2px`. Konsistent mit dem GHL-Design-System für Template-Library-Modals.
