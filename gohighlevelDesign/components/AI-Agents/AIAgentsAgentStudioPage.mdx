# AI-Assistenten – Agent Studio (Sections 121–121f)

Das Agent Studio (`AI-Assistenten → Agent Studio`) nutzt die **Highrise Library** (`hr-` Prefix). Scope ist `.agent-directory-content-wrap`. Diese MDX-Datei deckt 6 Sub-Sections ab:

- **121** — Agentenliste (DataTable, Alert, Sort, Pagination)
- **121b** — Neuer Ordner Modal (`#folder-modal`)
- **121c** — Agent erstellen Dropdown (`#create-agent-dropdown`)
- **121d** — Agent erstellen Modal (`#create-agent-modal`)
- **121e** — Tabellen-Header Extras (Selected-Tag, Bulk Actions)
- **121f** — Tabellen-Zeilen Extras (Checkboxen, Name-Link, Action-Dropdown)

Besonderheit: Highrise nutzt `--primary-600` CSS-Variablen direkt — diese werden am Root-Scope überschrieben statt per Klassen-Override.

## Besonderheiten

**`--primary-600` Root-Override:** Highrise rendert Button-Farben direkt via `var(--primary-600)` — kein Klassen-Override möglich. Lösung: CSS-Var auf `.agent-directory-content-wrap` selbst setzen, alle Kindkomponenten erben den Wert. Gleiches Pattern in `#folder-modal` und `#create-agent-modal`.

**Floating Dropdowns ohne Scope:** `#sort-dropdown`, `#create-agent-dropdown` und `[id^="action-dropdown-"]` werden außerhalb des DOM-Scopes gemountet. Globale ID-Selektoren nötig.

**`[id^="action-dropdown-"]` (Prefix-Selektor):** Das Zeilen-Action-Dropdown enthält eine dynamische UUID in der ID (z.B. `action-dropdown-abc123`). Der `^=`-Präfix-Selektor matched alle IDs die mit `action-dropdown-` beginnen — robuster als ein exakter Selektor.

**`data-v-23397495` Pagination:** Vue-Scoped-Attribut — kann sich nach GHL-Deployments ändern. Fallback: `.hr-pagination-item__active button` (ohne `data-v`).
