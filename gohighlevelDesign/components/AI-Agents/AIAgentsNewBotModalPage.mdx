# AI-Assistenten – Neuen Bot erstellen Modal (Section 120b)

Das „Neuen Bot erstellen"-Modal öffnet sich nach Klick auf „+ Erstellen" in Section 120. Es zeigt drei Bot-Typ-Karten (Geführte Formulareinrichtung / Prompt-basierter Bot / Flow-basierter Builder) mit je einem „Neuen Bot erstellen"-Button. Scope ist `.n-modal:has(#create-new-bot-button)`. Besonderheit: Die Bot-Typ-Icons sind Bilder (`<img>`) — sie werden via CSS `hue-rotate` von Blau (~220°) auf Wine/Rosa (~330°) getönt.

## Struktur & Root-Selektor

| Bereich | Selektor |
|---|---|
| Root (Scope-Anker) | `.n-modal:has(#create-new-bot-button)` |
| „Neuen Bot erstellen" Buttons | `#create-new-bot-button` |
| Empfohlen / Neu-Badge Text | `.text-primary-700` |

| Bot-Typ Icons | `img[alt="Bot-Typ Bild"]` |

## 120b.4 – Bot-Typ Icons (CSS hue-rotate)

```css
/* ── 120b.4 Bot-Typ Icons ── */
/* Blau (~220°) → Wine/Rosa (~330°) via hue-rotate(110deg) */
.n-modal:has(#create-new-bot-button) img[alt="Bot-Typ Bild"] {
  filter: hue-rotate(110deg) saturate(0.8) brightness(0.95) !important;
}
```

---

## Besonderheiten

**`hue-rotate` auf `<img>` Icons:** Die Bot-Typ-Icons sind Raster-Bilder, keine SVGs — kein `stroke`/`fill`-Override möglich. Der CSS `filter: hue-rotate(110deg)` dreht den Farbton von ~220° (Blau) auf ~330° (Rosa/Wine). `saturate(0.8)` dämpft die Sättigung leicht, `brightness(0.95)` verhindert zu helles Ergebnis. Dieses Pattern ist im gesamten Skin einzigartig.

**`#create-new-bot-button` als Scope-Anker im Modal:** Gleiche `:has()`-Strategie wie Section 120 — kein eigener Root-Identifier vorhanden, stabiler Button-ID als Ankerpunkt.

**Close-Button neutraler Border:** Der Close-Button würde auf Hover einen blauen NaïveUI-Default-Border zeigen. Da er kein wine-Verhalten benötigt, wird der Hover-Border explizit auf das neutrale Grau `rgb(224,224,230)` fixiert.
