# AI-Assistenten – Agentenprotokolle (Section 128)

Die Agent Logs Seite (`AI-Assistenten → Agent Logs`) zeigt eine DataTable mit Agentenaktivitätsprotokollen. Root-Scope ist `#agent-logs-content`. Die Seite enthält eine Suchleiste, Filter-Chips (Zeitstempel, Filter hinzufügen, Sortieren), einen Column Manager Popover (6/8 Spalten) und Pagination mit Rows-per-page Select.

Besonderheit: Die aktive Pagination-Seite wird via Vue-Scoped-Attribut `[data-v-23397495]` gestylt — zwei parallele Selektoren nötig (`#agent-logs-pagination` + `.hr-v-2-17-0`).

## Besonderheiten

**Vue-Scoped `[data-v-23397495]` für Pagination:** GHL setzt den aktiven Pagination-Border direkt via Vue-Scoped-Style mit einem `[data-v-*]` Attribut-Selektor (Spezifität: 0-1-1). Ohne den Attribut-Selektor im Override gewinnt der GHL-Style. Zwei Selektoren werden parallel gesetzt: `#agent-logs-pagination [data-v-23397495]` und `.hr-v-2-17-0 ... [data-v-23397495]` — letzerer als Fallback für andere Highrise-Versionen.

**`[id^="filter-apply-"]` und `[id^="filter-input-"]` (ID-Präfix):** Filter-Popovers erzeugen dynamische IDs pro Spalte (z.B. `filter-apply-agentName`, `filter-input-contactName`). Präfix-Selektor matched alle — gleiche Strategie wie `[id^="kb-action-button-"]` in Section 122 und `[id^="action-dropdown-"]` in Section 121f.

**`#remaining-column-checkbox` hat disabled-checked Sonderfall:** Pflicht-Spalten (Name des Agenten) sind checked + disabled. `var(--wine-lt)` statt `var(--wine)` signalisiert visuell den nicht-interaktiven Zustand.
