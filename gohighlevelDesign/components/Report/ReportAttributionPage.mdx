# Berichterstattung – Attributionsbericht (Section 116)

Der Attributionsbericht (`Berichterstattung → Attributionsbericht`) nutzt **NaïveUI** (`n-` Prefix) — im Gegensatz zu Sections 114/115 (Bootstrap). Scope ist `#attribution-dashboard`. Die Seite enthält einen Datepicker, Radio-Button-Pills (Erste / Letzte Zuordnung), einen Aktualisieren-Button, Stat-Karten, Sub-Tabs und ein Select-Dropdown für das Zeitintervall. Besonderheit: NaïveUI setzt viele Farben als CSS-Variablen per Inline-Style (`--n-bar-color`, `--n-dot-color-active` etc.) — diese müssen direkt auf dem betroffenen Element überschrieben werden.

## Besonderheiten

**NaïveUI CSS-Variablen als Inline-Style:** NaïveUI setzt viele Farbwerte direkt als CSS Custom Properties auf dem Element (z.B. `--n-bar-color: #18a058`). Diese müssen mit `--n-var: wert !important` auf dem gleichen oder einem Eltern-Element überschrieben werden — nicht über klassische Selektor-Überschreibungen.

**Radio-Pills vs. Radio-Circles:** Diese Seite verwendet beide NaïveUI Radio-Varianten: normale `.n-radio` (Kreise) für Einzel-Auswahl und `.n-radio-button` (Pills) für die Erste/Letzte-Zuordnung-Gruppe. Beide benötigen separate Overrides.

**Kein Bootstrap:** Im Gegensatz zu Sections 114/115 (Google/Facebook Ads) verwendet diese Seite NaïveUI — keine Bootstrap-Klassen wie `.btn-primary` oder `.page-item`.

**`:has()` Wrapper-Fix:** Der äußere `hl_topbar-tabs`-Wrapper wird gezielt via `:has(#attribution-dashboard)` selektiert — verhindert Kollisionen mit anderen Reporting-Tabs, die denselben Wrapper-Selektor teilen.
