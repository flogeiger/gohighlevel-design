# Berichterstattung – Neuer Bericht (Section 112b)

Die „Neuer Bericht"-Seite wird nach Klick auf „+ Neuer Bericht" in Section 112 geöffnet. Scope ist `#location-custom-reports`. Die Seite zeigt drei Auswahl-Karten (Leerer Bericht / Vorlagenbibliothek / Klonen), eine Sticky-Toolbar oben mit „Zurück"-Button und optional einen Dashboard-Select-Dropdown. NaïveUI (`n-button`, `n-base-selection`) wird verwendet.

![New Report Page Screenshot](./report-new-page-screenshot.png)

---

## Struktur & Root-Selektor

| Bereich | Selektor |
|---|---|
| Root | `#location-custom-reports` |
| Sticky Toolbar | `#location-custom-reports .hl-toolbar` |
| Zurück-Button | `#report_create-btn-back` |
| Auswahl-Karten | `#location-custom-reports .hl-card` |
| „Auswählen" / „Klon" Buttons | `.n-button--default-type` |
| Import-Button (primary) | `.n-button--primary-type` |

## 112b.1 – Toolbar

Sticky Top Bar mit Zurück-Button und wine-Trennlinie.

```css
/* ── 112b.1 Toolbar ── */
#location-custom-reports .hl-toolbar {
  border-bottom: 2px solid var(--wine-lt) !important;
}

/* Zurück-Button hover */
#location-custom-reports #report_create-btn-back:hover { color: var(--wine) !important; }
#location-custom-reports #report_create-btn-back:hover p,
#location-custom-reports #report_create-btn-back:hover svg { color: var(--wine) !important; }
```

## 112b.2 – Auswahl-Karten

Drei Karten mit Hover-State (wine Border + wine-lt Hintergrund) und Beschreibungstext.

```css

#location-custom-reports .hl-card:hover {
  border-color: var(--wine) !important;

  color: var(--wine) !important;
```

## 112b.3 – Buttons

„Auswählen" / „Klon" (default) und Import-Button (primary → wine).

```css
/* ── 112b.3 Buttons ── */
/* Default Buttons hover */
#location-custom-reports .n-button--default-type:not(#report_create-btn-back):hover {
  color: var(--wine) !important;
  border-color: var(--wine) !important;
}
#location-custom-reports .n-button--default-type .n-button__border { border-color: transparent !important; }
#location-custom-reports .n-button--default-type .n-button__state-border { display: none !important; }

#location-custom-reports .n-button--primary-type {
  background-color: var(--wine) !important;
  border-color: var(--wine) !important;

#location-custom-reports .n-button--primary-type .n-button__border { border-color: transparent !important; }
#location-custom-reports .n-button--primary-type .n-button__state-border { display: none !important; }
```

---

## Besonderheiten

**`:not(#report_create-btn-back)` Ausnahme:** Der Zurück-Button ist ebenfalls ein `n-button--default-type` — wird aber explizit ausgenommen, damit sein Hover separat mit nur `color: wine` (kein border) gestaltet werden kann.

**`border-color: transparent` auf `.n-button__border`:** Die Karten-Buttons haben im Default-State keinen sichtbaren Border — er wird erst auf Hover via `border-color: var(--wine)` eingeblendet. Daher transparent statt `var(--line-hard)` als Default.
