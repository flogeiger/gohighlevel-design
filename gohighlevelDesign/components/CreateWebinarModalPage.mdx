# Webinar-Funnel erstellen

Das **Create Webinar Funnel**-Modal öffnet sich aus der Webinars-Liste. Es hat zwei Stufen: **Stufe 1** zeigt eine Typ-Auswahl (On Demand / Live Webinar) mit Karten, **Stufe 2** öffnet einen 4-Step-Wizard mit Sidebar-Stepper (Webinar Details → Select Form → Select Video → Templates) und Formularfeldern. Der Modal-Scope nutzt `:has(#modal-header-modal-close-btn)` da keine eigene Root-ID existiert.

## Besonderheiten

**`:has()`-Scope ohne eigene Modal-ID:** Das Modal hat keine dedizierte Root-ID — der Scope `.hl-modal:has(#modal-header-modal-close-btn)` wird als Anker verwendet. Da `#modal-header-modal-close-btn` eine sehr generische ID ist, trifft dieser Scope potenziell auch andere Modals im Projekt — sollte in Zukunft auf eine spezifischere ID migriert werden wenn verfügbar.

**Webinar-Karten mit Inline-Style-Override:** Die farbigen Karten-Hintergründe (`background: rgb(255, 252, 245)`) werden über Attribut-Selektoren auf `var(--bg)` umgeleitet — da keine Klassen verfügbar sind. Dieser Ansatz ist fragil gegenüber RGB-Wert-Änderungen in GHL-Updates.

**Aktiv-ausgewählte Karte via Inline-Border:** Die ausgewählte Webinar-Karte hat `style="border: 2px solid ..."` als Inline-Style — überschrieben via `[style*="border: 2px solid"]` mit `var(--wine) !important`.

**`#prev` und `#next` als sehr generische Button-IDs:** Beide IDs könnten auf anderen Seiten kollidieren. Da GHL das Modal nur öffnet wenn der Webinars-Flow aktiv ist und das Modal im DOM liegt, entsteht in der Praxis kein Problem — der `html body`-Präfix sorgt für ausreichende Spezifität.
