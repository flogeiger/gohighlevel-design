# Reputation – Listings (Sections 96 & 96b)

Die Listings-Seite (`Ruf → Listings`) zeigt eine Upsell-Seite mit Carousel, Feature-Icons und CTA-Buttons. Root-Scope ist `#online-listings-container`. Das **Plan-Selector Modal** (`96b`) öffnet sich beim Klick auf „Auslöser-Listen" und enthält Radio-Button-Karten für drei Preispläne.

- **96** — Listings-Seite (`#online-listings-container`)
- **96b** — Plan Selector Modal (`.hr-modal:has(#plan-selector-modal-confirm-pitch)`)

## Besonderheiten

**Radio-Dot mit `box-shadow: inset 0 0 0 3px #ffffff`:** Der aktive Radio-Dot wird als ausgefüllter wine-Kreis mit weißem Kern dargestellt — `background-color: var(--wine)` + `box-shadow: inset 0 0 0 3px white`. Der Wrapper erhält explizit `background: transparent; box-shadow: none; border: none` um GHL-Default-Styles zu neutralisieren.

**`.hr-modal:has(#plan-selector-modal-confirm-pitch)` als Scope:** Das Modal hat keine eigene Root-ID — der `:has()`-Anker auf dem Confirm-Button ist der einzig stabile Selektor. Gleiche Strategie wie Section 123d/123e.

**`.yextApp` als Hintergrund-Selektor (Section 96):** GHL nutzt den Yext-Klassenamen für den Listings-Wrapper — weist auf die Yext-Integration hin.
