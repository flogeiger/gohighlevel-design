# Dashboard klonen Modal — CSS Dokumentation

Das **„Dashboard klonen"** Modal (`Section 102`) öffnet sich über das Kebab-Menü eines Dashboards. Es ermöglicht das Duplizieren eines Dashboards mit neuem Namen und optionalem Privat-Modus.

**Scope:** `body .hl-modal:has(#location-dashboard_modal-header--clone-dashboard-modal-close-btn)`

![Dashboard Klonen Modal Screenshot](/dashboard-clone-modal-screenshot.png)

---

## Betroffene Selektoren & Struktur

| Element | Selektor |
|---|---|
| Modal Shell | `body .hl-modal:has(#...clone-dashboard-modal-close-btn)` |
| Close Button | `#location-dashboard_modal-header--clone-dashboard-modal-close-btn` |
| Header Icon | `.icon.icon-success svg` |

## Besonderheiten

- **`.icon.icon-success` Hintergrund** — GHL setzt auf dem Icon-Container eine grüne Hintergrundfarbe via `.icon-success`. Fix: `background-color: transparent` direkt auf `.icon.icon-success` — das SVG selbst wird separat auf wine gesetzt.
- **Gleiche Toggle-ID wie Section 101** — `#location_dashboard_permissions_selector-switch-is_private` wird in beiden Modals (Berechtigungen + Klon) verwendet. Da beide Modals nie gleichzeitig offen sind, gibt es keinen Konflikt.
- **Struktur ähnlich Section 101** — Privates Dashboard Card (`.bg-gray-50`), Toggle und Footer-Buttons folgen exakt demselben Pattern wie das Berechtigungen-Modal.
