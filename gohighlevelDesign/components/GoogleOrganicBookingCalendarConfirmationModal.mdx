## 67.1 · Modal Container

Identisch zur Basisstruktur aus Section 65/66.

```css
.hl-modal {
  background: var(--surface) !important;
  border: 1px solid var(--line-hard) !important;
  border-radius: 12px !important;
  box-shadow: 0 8px 32px var(--ink-a12) !important;
  --n-color: var(--surface) !important;
  --n-color-modal: var(--surface) !important;
  --n-border-color: var(--line-hard) !important;
  --n-text-color: var(--ink-2) !important;
}
```

## 67.5 · Footer & Buttons

Footer mit hellem Hintergrund, Cancel Ghost-Button und primärem Confirm-Button.

```css
/* ── Footer */
.hl-modal .n-card__footer {
  background: var(--bg) !important;
  border-top: 1px solid var(--line-hard) !important;
  border-radius: 0 0 12px 12px !important;
}

/* ── Abbrechen / Cancel Button */
#generalConfirmationModalFooter-btn-negative-action {
  border-radius: 8px !important;
  font-weight: 600 !important;
  --n-border: 1px solid var(--line-hard) !important;
  --n-border-hover: 1px solid var(--wine) !important;
  --n-border-radius: 8px !important;
  --n-text-color: var(--ink-2) !important;
  --n-text-color-hover: var(--wine-2) !important;
}
#generalConfirmationModalFooter-btn-negative-action .n-button__border {
  border-color: var(--line-hard) !important;
  border-radius: 8px !important;
}
#generalConfirmationModalFooter-btn-negative-action .n-button__state-border {
  border-color: transparent !important;
}

/* ── Aktivieren / Confirm Button (::before Overlay) */
#generalConfirmationModalFooter-btn-positive-action {
  position: relative !important;
  overflow: hidden !important;
  border-radius: 8px !important;
  font-weight: 700 !important;
  --n-border: 1px solid var(--wine) !important;
  --n-border-radius: 8px !important;
}
#generalConfirmationModalFooter-btn-positive-action::before {
  content: "" !important;
  position: absolute !important;
  inset: 0 !important;
  background: var(--wine) !important;
  z-index: 0 !important;
  pointer-events: none !important;
}
#generalConfirmationModalFooter-btn-positive-action:hover::before {
  background: var(--wine-2) !important;
}
#generalConfirmationModalFooter-btn-positive-action .n-button__content {
  position: relative !important;
  z-index: 1 !important;
  color: var(--surface) !important;
}
#generalConfirmationModalFooter-btn-positive-action .n-button__border {
  border-color: var(--wine) !important;
  border-radius: 8px !important;
}
#generalConfirmationModalFooter-btn-positive-action .n-button__state-border {
  border-color: transparent !important;
}
```

---

> **Hinweis:** Dieses Modal verwendet dieselben Footer-Button IDs wie Section 65 (`#generalConfirmationModalFooter-btn-positive-action` / `-negative-action`). Der Unterschied zu Section 65 liegt im **Footer-Hintergrund** (`var(--bg)` statt transparent) und dem **Icon-Container** im Header. Das Modal wird für alle allgemeinen Bestätigungsaktionen im Kalender-Bereich wiederverwendet — der Button-Text ändert sich je nach Kontext ("Aktivieren", "Löschen", "Bestätigen" etc.).
