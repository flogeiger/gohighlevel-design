# Import Page — CSS Dokumentation

Die **„Importieren"** Seite (`Section 87`) ermöglicht den CSV-Import von Kontakten und Leads. Sie ist als **4-Schritt-Wizard** aufgebaut und wird unter `/opportunities/import` geöffnet.

| Schritt | Name | Inhalt |
|---|---|---|
| **1 · Start** | Objekte auswählen | Checkbox-Cards: Kontakte / Leads |
| **2 · Upload** | Datei hochladen | Drag & Drop Uploader + Import-Modus Dropdown |
| **3 · Map** | Felder zuordnen | Mapping-Handbuch + Datentabelle |
| **4 · Überprüfen** | Bestätigen | Auswahl bestätigen und abschließen |

**Scope:** `.scrollable-div-main`

---

### Checkbox-Cards (`.hl-checkbox-group-item`)
Die Objekt-Auswahl-Karten (Kontakte / Leads) sind als toggle-fähige Button-Karten implementiert. GHL nutzt dafür `.hl-checkbox-group-item` mit `.active`-Klasse für den selektierten Zustand.

```css
/* Default */
.scrollable-div-main .hl-checkbox-group-item {
  border: 1px solid var(--line-hard) !important;
  border-radius: 8px !important;
  background-color: #ffffff !important;
  --n-border-hover: 1px solid var(--wine) !important;
  --n-color-hover:  var(--wine-lt) !important;
}
.scrollable-div-main .hl-checkbox-group-item:hover {
  border-color: var(--wine) !important;
  background-color: var(--wine-lt) !important;
}

/* Ausgewählt */
.scrollable-div-main .hl-checkbox-group-item.active {
  border: 1px solid var(--wine) !important;
  background-color: var(--wine-lt) !important;
}
```

### Checkbox im Card

```css
}
```

## Besonderheiten

- **Stepper `finish`-Icon** — GHL rendert das Häkchen als `<img>`, nicht als SVG-inline. Fix: CSS `filter` zur Farbkonvertierung nach Wine.
- **Checkbox-Card State-Border** — GHL fügt bei Hover einen blauen `box-shadow` hinzu. Fix: `box-shadow: none` + eigener Wine-Border auf `.n-button__state-border`.
- **Card Icon Filter** — `brightness(0) saturate(100%) invert(23%) sepia(60%) saturate(400%) hue-rotate(300deg)` ist die berechnete Wine-Approximation für `#e9c2c5`-nahe Töne auf `<img>`-Elementen.
- **Dropdown Options** (`.n-base-select-option`) sind global gescopert — kein Parent-Kontext möglich da teleportiert.
- **3 Nächste-Button-IDs** — GHL erstellt pro Schritt einen neuen Button mit eigener ID (`-1`, `-2`, `-3`). Alle drei müssen explizit angesprochen werden.
