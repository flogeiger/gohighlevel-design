# Reputation – Listings Scan Form (Section 97)

Die Listings Scan-Ansicht öffnet sich nach Klick auf „Scannen Sie mein Unternehmen". Gleicher Scope `#online-listings-container` wie Section 96. Die Seite zeigt einen Step-Indicator links, eine Upsell-Card (Auslöser-Listen) und rechts ein Scan-Formular mit Business-Daten-Inputs.

| Bereich | Selektor |

## Besonderheiten

**Gleicher Scope wie Section 96:** Section 97 ist eine Unteransicht innerhalb von `#online-listings-container` — kein eigener Root-Scope. GHL rendert die Scan-Ansicht per Vue-Router in denselben Container.

**`#activeate-yext` (Tippfehler in GHL-ID):** Die Button-ID enthält einen Tippfehler (`activeate` statt `activate`) — dieser Selektor muss exakt so übernommen werden.

**`.bg-success-100`, `.bg-warning-100`, `.bg-gray-100` → wine-lt:** Die Feature-Icon-Badges nutzen verschiedene Semantic-Color-Klassen (success = grün, warning = gelb, gray = grau) — alle werden auf `var(--wine-lt)` vereinheitlicht, da sie im Kontext der Upsell-Card nur dekorativ sind.
