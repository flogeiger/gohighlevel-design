# Reputation – Widgets (Sections 95 & 95b)

Die Widgets-Seite (`Ruf → Widgets`) zeigt eine Widget-Vorschau links und eine Sidebar rechts mit Segment-Tabs (Gespeicherte Widgets / Vorlagen), Template-Cards und einem „Widget bearbeiten"-Button. Dazu gehört das **Widget-Code Modal** (`#widget-copy-code-modal`) mit Code-Textarea, Widget-Select und „Code kopieren"-Button.

- **95** — Widgets-Seite (`#widgets-container`)
- **95b** — Widget-Code Modal (`#widget-copy-code-modal`)

## Besonderheiten

**`[id^="copy-code-button"]` (ID-Präfix):** Der Code-kopieren-Button hat eine dynamische ID pro Widget — Präfix-Selektor matched alle Instanzen. Gleiches Pattern wie `[id^="filter-apply-"]` in Section 128.

**Template-Cards via `[role="button"].rounded-xl`:** Die Widget-Template-Kacheln haben keine GHL-IDs — ARIA-Attribut + Tailwind-Klasse als Selektor.

**Segment-Tabs via `.hr-tabs-rail`:** Aktive Kapsel-Markierung über Highrise-spezifische `.hr-tabs-rail` Klasse (nicht NaïveUI `--n-bar-color`). Gleiche Methode wie Section 93b.
