# AI-Assistenten – Wissensdatenbank Detail/Bearbeiten (Sections 122d–122j)

Die Wissensdatenbank-Detailseite öffnet sich nach Klick auf eine Datenbank in der Liste. Scope ist `#edit-knowledge-base-card`. Sie hat 6 Tabs: **Alle**, **Web-Crawler**, **FAQ**, **Tabellen**, **Rich-Text**, **Datei-Upload** — jeder Tab öffnet sein eigenes Modal. Diese MDX-Datei deckt alle Sub-Sections ab:

- **122d** — Detailseite (Tabs, Quick-Action Tags, Bearbeiten-Stift)
- **122e** — Tab-Inhalte allgemein (Buttons, Inputs, Checkboxen, Status-Badges)
- **122f** — „Website hinzufügen" Modal (`#web-crawling-modal`)
- **122g** — FAQ Modal (`#faq-addition-modal`)
- **122h** — Tabellen-Upload Modal (`#table-upload-modal`, 3 Schritte)
- **122i** — Rich-Text Editor Modal (`#rich-text-editor-modal`)
- **122j** — Datei-Upload Modal (`#file-upload-modal`)

## Besonderheiten

**`color-mix()` auf Tag-Hover:** Section 122d nutzt `color-mix(in srgb, var(--wine) 12%, white)` für den Hover-Hintergrund der Quick-Action Tags — einzige Stelle im Projekt mit dieser CSS-Funktion. Browser-Support: Chromium 111+, Firefox 113+.

**`.hr-tag--success` bleibt grün (122e):** Status-Badges mit Erfolgs-Bedeutung (z.B. „Crawled") behalten bewusst grüne Farbe — nur `.hr-tag--blue` (neutrale Info-Tags) werden auf wine umgefärbt.

**Tabellen-Upload 3 Schritte — doppelte Pagination:** Schritt 2 hat zwei Pagination-Instanzen (`v-0` für Dateivorschau, `v-1` für Spaltenauswahl), beide mit eigenen `#hr-prev-button-v-{n}` / `#next-button-v-{n}` IDs.

**Rich-Text Tiptap Editor:** Der Editor nutzt das Tiptap-Framework — Wrapper-Border und Focus-Shadow werden auf `.hr-editor__wrapper:focus-within` gesetzt, nicht auf `.tiptap` direkt (das hat `outline: none`).
