# Schnell-Filter Drawer — CSS Dokumentation

Der **„Schnell-Filter"** Drawer (`Section 99`) öffnet sich über den „+ Schnell-Filter" Button auf der Dashboard-Seite. Er hat zwei Zustände die dynamisch wechseln:

| State | Beschreibung | Trigger |
|---|---|---|
| **State A · Leer** | Empty State mit „Schnell-Filter Hinzufügen" Button | Initial beim Öffnen |
| **State B · Filter hinzufügen** | Suchfeld + Modul-Dropdown + Collapse-Liste | Nach Klick auf „+ Schnell-Filter Hinzufügen" |

**Scope:** `.hl-drawer-content:has(.quick-filter-custom-height)`

## Besonderheiten

- **Scope via `:has()`** — Der Drawer hat keine eigene ID. Die Scoping-Strategie nutzt `.hl-drawer-content:has(.quick-filter-custom-height)` als eindeutigen Container-Selektor.
- **State A → B Wechsel** — Beide States befinden sich im selben Drawer-Scope. GHL blendet State A aus und zeigt State B an — kein DOM-Wechsel, kein zusätzlicher Scope nötig.
- **„Klären" Button deaktiviert** — Solange keine Filter vorhanden sind, ist `#location_dashboard_quick_filters-btn-clear_filters` funktional deaktiviert. `opacity: 0.5` signalisiert den inaktiven Zustand ohne den Wine-Override zu ändern.
- **`#search-input` globale ID** — Diese ID wird auch in anderen Drawers verwendet (z.B. Section 88). Der Schnell-Filter Drawer ist durch seinen übergeordneten Scope (`:has(.quick-filter-custom-height)`) ausreichend isoliert.
