# Reputation – Bewertungsanfrage Modal (Section 93b)

Das Review Request Modal (`#send-review-request-modal`) öffnet sich beim Klick auf „Anfrage senden". Es enthält ein Kontakt-Select, Telefon- und E-Mail-Input, Kanal-Checkboxen (Email, SMS, WhatsApp), Segment-Tabs für den Nachrichteninhalt, einen Info-Banner und einen Footer mit Send-Button.

## Besonderheiten

**`bg-blue-50` Tailwind-Klasse als Attribut-Selektor:** Der Info-Banner nutzt eine Tailwind-Utility-Klasse direkt als Selektor — kein GHL-spezifischer Scope. Da der Scope `#send-review-request-modal` vorgestellt ist, trifft der Override nur innerhalb des Modals.

**Segment-Tabs via `.hr-tabs-rail`:** Die aktive Tab-Kapsel wird durch `.hr-tabs-rail` (Highrise-spezifisch) markiert — nicht via NaïveUI `--n-bar-color`. Direktes `background-color` auf `.hr-tabs-rail`.

**`:not(:disabled)` auf Send-Button Hover:** Der Button ist initial disabled (solange kein Kontakt gewählt) — `:not(:disabled)` verhindert einen wine-Hover auf dem deaktivierten Zustand.
