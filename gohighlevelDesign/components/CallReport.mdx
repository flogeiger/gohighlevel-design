# Berichterstattung – Bericht anrufen (Section 117)

Der Anruf-Bericht (`Berichterstattung → Bericht anrufen`) nutzt **NaïveUI** (`n-` Prefix). Scope ist `#call-reporting-dashboard`. Die Seite enthält Tabs (Ankommend / Ausgehend), Datepicker, Select-Dropdown, Filter-Button, Aktualisieren- und Layout-Button sowie Donut-Charts. Der Filter-Drawer ist ein NaïveUI-Drawer mit neun Select-Feldern, einem Duration-Input mit +/- Buttons und zwei Toggle-Switches.

## Besonderheiten

**Toggle-Switches via `aria-checked`:** NaïveUI Switches setzen den aktiven Hintergrund über eine CSS Custom Property `--n-rail-color-active`. Da diese als Inline-Style gesetzt werden kann, ist zusätzlich ein direkter Override via `[aria-checked="true"] .n-switch__rail` nötig — beide Wege zusammen sichern zuverlässig den wine-Hintergrund.

**9 Filter-Selects einzeln gelistet:** Die Filter-Drawer-Selects haben alle IDs nach Schema `#call-reporting-dashboard_select--filter-{name}`. Da sie im Drawer außerhalb des normalen DOM-Flows gerendert werden, können sie nicht über den übergeordneten `#call-reporting-dashboard` Scope erreicht werden — jeder ID-Selektor muss explizit aufgeführt werden.

**`:has()` Wrapper-Fix:** Gleiche Strategie wie Section 116 (Attribution) — verhindert Kollisionen mit anderen Reporting-Tabs.
