# Filter Drawer — CSS Dokumentation

Diese Seite dokumentiert den **„Filters"** Drawer (`Section 86`) im SalonQueen GHL Whitelabel. Der Drawer hat zwei Ansichten die dynamisch wechseln:

| View | Beschreibung | Scope |
|---|---|---|
| **86-A · Haupt-Filterliste** | Alle Filterkategorien als Wine-Buttons | `:has(#assigned_to)` |
| **86-B · Sub-Panel** | Checkbox-Liste nach Klick auf eine Kategorie | `:has(#data-back)` |

> Wenn das Sub-Panel offen ist, ist `#assigned_to` **nicht mehr im DOM** — daher brauchen beide Scopes eigene Selektoren.

---

## 86-A · Haupt-Filterliste

![Filter Drawer Hauptansicht Screenshot](/opportunities-filter-drawer-main-screenshot.png)

**Scope:** `.hr-drawer-content-wrapper:has(#assigned_to)`

Die Filterkategorien (Owner, Followers, Status, etc.) werden als **Wine-farbene Buttons** mit weißer Schrift und Chevron dargestellt.

### Filter Rows
```css
.hr-drawer-content-wrapper:has(#assigned_to) .mb-3.flex.h-12.rounded-md {
  background-color: var(--wine) !important;
  border-radius: 8px !important;
}
.hr-drawer-content-wrapper:has(#assigned_to) .mb-3.flex.h-12.rounded-md:hover {
  background-color: var(--wine-2) !important;
}
/* Label Text weiß */
.hr-drawer-content-wrapper:has(#assigned_to) .mb-3.flex.h-12 .font-medium {
  color: var(--surface) !important;
}
/* Chevron-SVG weiß (stroke="currentColor") */
.hr-drawer-content-wrapper:has(#assigned_to) .mb-3.flex.h-12 svg {
  color: var(--surface) !important;
  stroke: var(--surface) !important;
}
```

### Active-Count-Badge
Wenn ein Filter aktiv ist, zeigt GHL einen blauen Badge — wird auf halbtransparentes Weiß überschrieben:
```css
.hr-drawer-content-wrapper:has(#assigned_to) .bg-blue-100 {
  background-color: rgba(255, 255, 255, 0.25) !important;
}
.hr-drawer-content-wrapper:has(#assigned_to) .text-blue-500 {
  color: var(--surface) !important;
}
```

### Header Icon
Das GHL-Icon im Drawer-Header hat mehrere Ebenen (Rechteck-Container, äußerer/innerer Kreis, SVG):
```css
/* Rechteck-Container → transparent */
... .ui-icon-container { background: transparent !important; }
/* Äußerer Kreis → wine */
... .icon-primary::before { background-color: var(--wine) !important; }
/* Innerer Kreis → wine-lt */
... .icon-primary::after  { background-color: var(--wine-lt) !important; }
/* SVG → wine */
... .ui-drawer-header-icon svg { stroke: var(--wine) !important; }
```

## 86-B · Sub-Panel (Checkbox-Liste)

![Filter Drawer Sub-Panel Screenshot](/opportunities-filter-drawer-subpanel-screenshot.png)

**Scope:** `.hr-drawer-content-wrapper:has(#data-back)`

Nach Klick auf eine Filterkategorie öffnet sich das Sub-Panel mit Suchfeld, Checkbox-Liste und Footer-Buttons.

### Back Button
```css
.hr-drawer-content-wrapper:has(#data-back) #data-back {
  color: var(--ink-3) !important;
}
.hr-drawer-content-wrapper:has(#data-back) #data-back:hover {
  color: var(--wine) !important;
}
```

### Search Input (`#data-filter-search`)
```css
.hr-drawer-content-wrapper:has(#data-back) #data-filter-search {
  --n-border-hover:     1px solid var(--wine) !important;
  --n-border-focus:     1px solid var(--wine) !important;
  --n-box-shadow-focus: 0 0 0 2px var(--wine-ring) !important;
  --n-caret-color:      var(--wine) !important;
}
.hr-drawer-content-wrapper:has(#data-back) #data-filter-search .hr-input__border {
  border: 1px solid var(--line-hard) !important;
  border-radius: 6px !important;

```

### Checkboxen
```css
.hr-drawer-content-wrapper:has(#data-back) .hr-checkbox {
  --n-border-checked: 1px solid var(--wine) !important;
  --n-color-checked:  var(--wine) !important;
}
.hr-drawer-content-wrapper:has(#data-back) .hr-checkbox--checked .hr-checkbox-box {

  border-color: var(--wine) !important;
```

### Radio Buttons (Is / Is not / Is empty… Sub-View)
Gleicher Override wie in Section 84 — CSS-Vars direkt auf `.hr-radio__dot-wrapper` deklarieren:
```css
.hr-drawer-content-wrapper:has(#data-back) .hr-radio .hr-radio__dot-wrapper {
  --n-box-shadow:        inset 0 0 0 1px var(--line-hard) !important;
  --n-box-shadow-active: inset 0 0 0 1px var(--wine) !important;
  --n-box-shadow-hover:  inset 0 0 0 1px var(--wine) !important;
  --n-box-shadow-focus:  inset 0 0 0 1px var(--wine), 0 0 0 2px var(--wine-ring) !important;
}
.hr-drawer-content-wrapper:has(#data-back) .hr-radio__dot.hr-radio__dot--checked {
  background-image: linear-gradient(var(--wine), var(--wine)) !important;
}
```

### Text Input (`#data-input`)
Erscheint bei Freitextfiltern (z.B. Opportunity Value):
```css
.hr-drawer-content-wrapper:has(#data-back) #data-input {
  --n-border-hover:     1px solid var(--wine) !important;
  --n-border-focus:     1px solid var(--wine) !important;
  --n-box-shadow-focus: 0 0 0 2px var(--wine-ring) !important;
  --n-caret-color:      var(--wine) !important;
}
```

### Footer Buttons
```css
/* Stornieren (Ghost) */
#filter-level-one-btn-negative-action .hr-button__content { color: var(--ink-2) !important; }
#filter-level-one-btn-negative-action:hover .hr-button__content { color: var(--wine) !important; }

/* Anwenden (Primary) */
#filter-level-one-btn-positive-action {
  background-image: linear-gradient(var(--wine), var(--wine)) !important;
}
```

## Gemeinsame Regeln (86-A + 86-B)

Shell, Header, Titel und Close Button sind identisch — comma-separated Scopes:

```css
.hr-drawer-content-wrapper:has(#assigned_to) .hr-drawer-content,
.hr-drawer-content-wrapper:has(#data-back) .hr-drawer-content {
  background-color: var(--surface) !important;
}

.hr-drawer-content-wrapper:has(#assigned_to) .hr-drawer-header__close:hover,
.hr-drawer-content-wrapper:has(#data-back) .hr-drawer-header__close:hover {
  background-color: var(--wine-lt) !important;
  color: var(--wine) !important;
}
```

---

## Besonderheiten

- **DOM-Wechsel beim Sub-Panel** — `#assigned_to` verschwindet aus dem DOM wenn das Sub-Panel geöffnet wird. Deshalb zwei separate Scopes statt einem gemeinsamen.
- **Filter Rows als Tailwind-Klassen** — `.mb-3.flex.h-12.rounded-md` ist keine semantische GHL-Klasse, sondern direkte Tailwind-Utility-Klassen. Änderungen am GHL-Markup könnten diese Selektoren brechen.
- **Header Icon Layering** — das Filter-Icon hat 3 Ebenen (Container-Rechteck, `::before` Outer-Circle, `::after` Inner-Circle). Alle drei müssen explizit überschrieben werden.
- **Radio-Sub-View** — erscheint nur bei bestimmten Filtertypen (z.B. „Opportunity Value", „Created on") die einen Is/Is-not Operator anbieten.
