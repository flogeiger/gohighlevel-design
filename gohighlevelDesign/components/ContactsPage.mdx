# Kontakte – Listenansicht (Section 109)

Die Kontakte-Seite verwendet die **Highrise Component Library** (`hr-` Prefix) statt NaïveUI (`n-` Prefix). Die Tabelle wird von **Tabulator.js** gerendert — einem eigenständigen Grid-Framework mit eigenen Selektoren. Die Seite gliedert sich in: Pipeline Ribbon (Header), Views-Bar, Quick Filter Bar, Tabulator-Grid und Footer-Pagination.

![Contacts Page Screenshot](./contacts-page-screenshot.png)

---

## Struktur & Root-Selektor

| Bereich | Selektor |
|---|---|
| Root | `.hr-config-provider`, `.platform-ui__highrise` |
| Header Bar | `.pipeline-ribbon` |
| Views Bar | `#views-bar` |
| Quick Filter Bar | `.quick-filter-bar` |
| Tabulator Header | `.tabulator-header`, `.tabulator-col` |
| Tabulator Rows | `.tabulator-row`, `.tabulator-cell` |
| Tabulator Footer | `.tabulator-footer` |
| Bulk Actions | `.bulk-actions` |

> **Wichtig:** Diese Seite verwendet `hr-button` statt `n-button`. Die CSS-Custom-Properties heißen entsprechend `--hr-*` bzw. müssen direkt auf `background-color` gesetzt werden, da NaïveUI-Vars hier nicht greifen.

## Besonderheiten

**`hr-` statt `n-` Prefix:** Die Kontakte-Seite nutzt die Highrise Component Library. Button-Klassen lauten `.hr-button`, `.hr-button__border`, `.hr-button__content` — nicht `.n-button` wie im Rest der Plattform.

**Tabulator.js Pagination:** Tabulator setzt `color: #175CD3` direkt per JavaScript als Inline-Style auf aktive Pagination-Buttons. Normale `!important` CSS-Regeln werden überschrieben. Der „nuclear override" mit `.my-table.tabulator .tabulator-footer .tabulator-paginator` erhöht die Spezifität soweit, dass er greift.

**`hr-button` Hover:** NaïveUI-CSS-Vars wie `--n-color-hover` greifen hier nicht. Stattdessen müssen `background-color` und `background` direkt auf dem Element mit maximal hoher Spezifität (`button#id:hover`) überschrieben werden.

**Views-Bar `::after`-Streifen:** GHL rendert den aktiven blauen Streifen als `::after`-Pseudo-Element auf `.view.active`. Dieser wird mit `display: none !important; content: none !important` entfernt und durch einen direkten `border-bottom: 2px solid var(--wine)` auf dem Element ersetzt.

**Checkbox-Pattern:** Identisches `appearance: none` + `::after` Häkchen-Pattern wie in Section 108 (Conversations). Wird einheitlich auf Header-Checkbox (`.tabulator-col.selector`) und Row-Checkboxen (`.tabulator-cell.selector`) angewendet.
