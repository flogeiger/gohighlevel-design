# Marketing – Countdown-Timer (Sections 102–102e)

Die Countdown-Timer-Seite (`Marketing → Countdown-Timer`) zeigt eine DataTable mit angelegten Timern, Filter-Button, Suchfeld und Pagination. Root-Scope ist `#countdownTimer`. Der Builder öffnet sich vollbildschirmig beim Erstellen/Bearbeiten eines Timers.

- **102** — Hauptliste (DataTable, Filter, Pagination)
- **102b** — Builder Template-Auswahl (Sidebar, Template-Cards)
- **102c** — Builder Einstellungs-Sidebar (Tabs, Radio Cards, Inputs, Selects)
- **102d** — Dropdown Popovers (`.countdownTimerApp`)
- **102e** — Tabellen-Footer & Pagination

## Besonderheiten

**`.countdownTimerApp` als Dropdown-Scope:** Dropdowns werden außerhalb von `#countdownTimer` in einem eigenen Teleport-Container gemountet — Scope wechselt auf die Klasse `.countdownTimerApp`.

**Builder ist Fullscreen:** Section 102b/102c öffnen einen vollbildschirmigen Builder-View innerhalb von `#countdownTimer` — kein eigenes Root-Element, gleicher Container-Scope.

**Template-Card Hover via `outline`:** `.countdown-timer-item-list:hover` nutzt `outline: 2px solid var(--wine)` statt `border` — verhindert Layout-Shift durch Borderbreite.
