# Reputation – Bewertungen (Section 94)

Die Bewertungen-Seite (`Ruf → Bewertungen`) zeigt alle eingegangenen Reviews mit AI-Zusammenfassungs-Toggle, Rating-Karte mit Progress-Bars, Filter-Selects (Bewertungen, Quellen, Datum, Suche) und Review-Cards. Root-Scope ist `#reviews-container`.

## Besonderheiten

**AI-Zusammenfassung Gradient Text:** GHL nutzt CSS `-webkit-text-fill-color: transparent` + `background: linear-gradient(...) text` für den Gradient-Effekt auf dem AI-Summary-Text. Der Gradient läuft von `var(--wine-2)` → `var(--wine)` — dunkel nach hell.

**`svg[style*="rgb(74, 31, 184)"]` Attribut-Selektor:** Das AI-Icon hat einen Inline-Style mit lila Farbe (`rgb(74, 31, 184)`) — Attribut-Selektor nötig um es auf wine-2 umzufärben. Gleiche Strategie wie Support-Links in Section 126.

**Quellen-Select via globalem `.hr-base-selection`:** Dieser Select hat keine eigene ID — der Scope `#reviews-container .hr-base-selection` greift auf alle hr-Selects im Scope. Kein Kollisions-Risiko da der Scope eng ist.
