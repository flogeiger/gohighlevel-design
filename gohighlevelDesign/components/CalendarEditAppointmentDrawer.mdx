## 79.9 · Footer Buttons (Cancel & Save)

"Cancel" Ghost-Button und "Save" Wine-Primär — eigene IDs `#drawer-cancel` / `#drawer-save` (abweichend von Sec 74–76).

```css
/* ── Cancel */

  border-radius: 8px !important;
  transition: all 0.12s !important;
}
#drawer-cancel:hover { background: var(--wine-lt) !important; }
#drawer-cancel .n-button__border {
  border-color: var(--line-hard) !important;
  border-radius: 8px !important;
}
#drawer-cancel:hover .n-button__border { border-color: var(--wine) !important; }
#drawer-cancel .n-button__state-border { border-color: transparent !important; }
#drawer-cancel .n-button__content { color: var(--ink-2) !important; }
#drawer-cancel:hover .n-button__content { color: var(--wine-2) !important; }

/* ── Save */
#drawer-save {
  background-color: var(--wine) !important;
  border: 1px solid var(--wine) !important;
  border-radius: 8px !important;
  box-shadow: 0 2px 8px var(--wine-glow) !important;
  transition: transform 0.12s, box-shadow 0.12s, background-color 0.12s !important;
}
#drawer-save:hover {
  background-color: var(--wine-2) !important;
  border-color: var(--wine-2) !important;
  transform: translateY(-1px) !important;
  box-shadow: 0 4px 14px var(--wine-glow) !important;
}
#drawer-save .n-button__content { color: var(--surface) !important; }
#drawer-save .n-button__border { border-color: var(--wine) !important; border-radius: 8px !important; }
#drawer-save .n-button__state-border { border-color: transparent !important; }
```

---

> **Hinweis:** Der Default/Custom-Toggle (`#buttonGroupSlotManager`) nutzt das `::before` Overlay Pattern — da GHL den aktiven Button-Hintergrund per JS als Inline-Style setzt, wird er mit einem absolut positionierten `::before`-Pseudo-Element überschrieben (identisch zu `#book-appt-default`/`#book-appt-custom` in der BookAppointmentModal, Section 69). Die Footer-Button IDs `#drawer-cancel` / `#drawer-save` sind hier **anders** als in Section 74–76 (`#drawer-component-btn-negative/positive-action`).
