# AI-Assistenten – Vorlagenbibliothek Modal (Section 122)

Das Vorlagenbibliothek-Modal öffnet sich im Agent Studio beim Auswählen einer Vorlage. Scope ist `#tl-location-wrapper`. Die Seite nutzt die **Highrise Library** (`hr-` Prefix) mit `--primary-*` CSS-Variablen. Aufbau: linke Sidebar mit Kategorie-Filtern (Collapse + Checkboxen), rechter Hauptbereich mit Filter-Bar (Suchfeld, Sort-Select, Grid/List-Toggle) und Vorlagen-Kacheln.

## Besonderheiten

**`--primary-600` + `--primary-700` beide überschrieben:** Im Gegensatz zu Section 121 (nur `--primary-600`) verwendet diese Seite zusätzlich `--primary-700` für aktive Sidebar-Filter-Texte — beide werden auf `var(--wine)` gesetzt.

**`#tl-filterbar-input-search` ohne Scope-Präfix:** Das Suchfeld-Element hat eine eigene ID außerhalb des `#tl-location-wrapper`-Scopes — direkte ID-Selektion nötig.

**Vorlagen-Kacheln bleiben unverändert:** Die Vorlagen-Thumbnail-Bilder (z.B. blaue Agent-Grafiken) sind externe Bilder — kein CSS-Override. Nur UI-Elemente (Buttons, Checkboxen, Hover-States) werden angepasst.
