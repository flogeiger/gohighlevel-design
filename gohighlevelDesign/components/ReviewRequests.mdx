# Reputation – Anfragen (Section 93)

Die Review Requests Seite (`Ruf → Anfragen`) zeigt eine Liste gesendeter Bewertungsanfragen. Root-Scope ist `#review-requests-container`. Die Seite enthält zwei Header-Buttons, ein Suchfeld, zwei Filter-Selects (Status, Gesendet über) und einen Empty-State.

![Review Requests Screenshot](./review-requests-screenshot.png)

---

## Struktur & Root-Selektor

| Bereich | Selektor |
|---|---|
| Root | `#review-requests-container` |
| „Bewertungslink konfigurieren" | `#configure-review-link-button` |
| „Anfrage senden" (Header + Empty) | `#send-review-request-button`, `#empty-review-request-message-btn-positive-action` |
| Suchfeld | `#review-requests-search-filter` |
| Status-Filter | `#review-requests-status-filter .hr-base-selection` |
| Methoden-Filter | `#review-requests-method-filter .hr-base-selection` |
| Empty-State | `.ui-empty-icon-container`, `.ui-empty-icon`, `.ui-empty-title`, `.ui-empty-description` |

## Besonderheiten
