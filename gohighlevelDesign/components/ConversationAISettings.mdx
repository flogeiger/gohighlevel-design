# AI-Assistenten – Conversation AI Einstellungen (Sections 124–124d)

## Besonderheiten

**`img` via `filter: brightness(0) invert(1)` (Upgrade-Button):** Das Upgrade-Button-Icon ist ein `<img>` Element — kein SVG. Da der Button wine-gefärbt ist, wird das Bild via CSS-Filter auf weiß gebracht. Gleiche Technik wie hue-rotate in anderen Sections, aber hier für reines Weiß.

**Radio-Karten-Border via `box-shadow` (nicht `border`):** NaïveUI rendert den aktiven Rahmen von Radio-Button-Karten als `box-shadow: inset 0 0 0 1px` — kein echter `border`. Entsprechend wird der Override ebenfalls via `box-shadow` gesetzt.

**Checkboxen direkt auf `.n-checkbox-box` (124c):** Im Bot-Ziele Tab reichen die CSS-Variablen `--n-color-checked` nicht aus — NaïveUI setzt `background-color` als Inline-Style direkt auf `.n-checkbox-box`. Direktes Element-Override nötig.

**Drei unterschiedliche Save-Button-IDs:** Jeder Tab hat seine eigene Save-Button-ID: `#save-ai-employee` (124), `#save-knowledge-base-changes` (124b), `#save-conversation-ai-setting` (124c/d).
