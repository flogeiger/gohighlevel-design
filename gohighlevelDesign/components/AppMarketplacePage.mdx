# App-Marktplatz (Sections 113 & 113b)

Der App-Marktplatz (`App-Marktplatz`) nutzt ausschließlich die **Highrise Component Library** (`hr-` Prefix). Root-Scope ist `#marketplace-app`. Die Seite enthält horizontale Tabs, einen View-Selector-Dropdown, ein Suchfeld, eine Filter-Sidebar (Collapse + Checkboxen + Radio-Buttons), App-Kacheln mit Sternebewertung und Pagination.

**Neu in dieser Version:** Section **113b** (Pricing-Modal) und überarbeitete Radio-Button- und Checkbox-Patterns mit vollständigen Fokus/Hover/Checked-States.

## Besonderheiten

**Radio-Button `.hr-radio__dot` statt `__dot-wrapper`:** Die neue Version targetiert `.hr-radio__dot` direkt (nicht `.hr-radio__dot-wrapper`). Der checked-Innenpunkt wird via `::before` auf dem `__dot--checked` Element gesetzt — `background-color: var(--wine)`.

**Checkbox Hover-Checked State:** Expliziter Override für `.hr-checkbox--checked:hover` → `var(--wine-2)` (Darkening on hover im Checked-State).

**Tertiary-Buttons mit `:not(.hr-button--primary)`:** Verhindert Kollisionen wenn Tertiary + Primary Klassen kombiniert werden.

**113b Pricing Modal teleportiert:** Das Modal liegt außerhalb des `#marketplace-app` DOM-Baums — globale `.hr-modal.ui-modal` Selektoren. Gleiches Problem wie Context-Menu (Section 116) und Bootstrap-Select-Checkmarks (Section 119).

**Primary-Button Text explizit weiß:** NaïveUI setzt `--n-text-color` als Inline-Style intern — `background-color` allein reicht nicht. Direktes `.hr-button__content, .hr-button__content *, .hr-button__content p { color: #ffffff }` sichert weiße Schrift.
