# App-Marktplatz (Section 113)

Der App-Marktplatz (`App-Marktplatz`) nutzt ausschließlich die **Highrise Component Library** (`hr-` Prefix). Root-Scope ist `#marketplace-app`. Die Seite enthält horizontale Tabs, einen View-Selector-Dropdown, ein Suchfeld, eine Filter-Sidebar (Collapse + Checkboxen + Radio-Buttons), App-Kacheln mit Sternebewertung und Pagination. Besonderheit: Radio-Buttons müssen über `box-shadow` auf `.hr-radio__dot-wrapper` direkt gestylt werden — CSS-Variablen-Overrides auf dem Label-Element greifen nicht zuverlässig.

## Besonderheiten

**Radio-Button `box-shadow`-Trick:** GHL rendert den Radio-Ring via `box-shadow: inset 0 0 0 1.5px <farbe>` direkt auf `.hr-radio__dot-wrapper`. CSS-Variablen-Overrides auf dem Label-Element (`--n-box-shadow-*`) greifen nicht zuverlässig, weil Highrise sie als Inline-Style setzt. Der direkte `box-shadow`-Override auf `.hr-radio__dot-wrapper` mit `:hover`-Scope ist die einzig verlässliche Lösung — gleiches Muster wie in Section 84 (Leads Kanban).

**`✓ WL`-Tag bleibt hellblau:** Das „White Label"-Badge signalisiert Drittanbieter-Kompatibilität — es wird bewusst nicht auf Wine umgefärbt, da es eine Drittanbieter-Kennzeichnung ist.

**Doppelte Pagination-Klassen:** GHL nutzt auf dieser Seite zwei verschiedene Pagination-Systeme: `.hr-pagination-item--active` (ältere Variante) und `.hr-pagination-item__active` (neuere `hr-pagination-cntr`-Variante). Beide müssen separat gestylt werden.

**Segment-Tab Text auf Wine-Capsule:** Aktiver Tab-Text muss explizit `color: #fff` gesetzt bekommen — er sitzt auf der wine-farbenen Capsule und wäre sonst wine-on-wine nicht lesbar.
