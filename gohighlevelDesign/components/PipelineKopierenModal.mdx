# Pipeline In Unterkonten kopieren Modal — CSS Dokumentation

Das **„In Unterkonten kopieren"** Modal (`Section 92`) öffnet sich über das Kebab-Menü einer Pipeline-Zeile. Es erlaubt das Kopieren einer Pipeline (inkl. Phasen + Diagrammsichtbarkeit) in ein oder mehrere Unterkonten.

**Scope:** `#pipeline-copy-sub-account-modal`

## Besonderheiten

- **Tag `.hr-button__border` Pattern** — Ausgewählte Tags haben wie Buttons ein separates `.hr-tag__border` Div. Border-Farbe muss direkt auf dieses Div gesetzt werden — nicht via CSS-Variable.
- **Multi-Select Tags** — GHL rendert ausgewählte Unterkonten als inline-Tags im Select-Feld (nicht als Chips außerhalb). Der Scope ist `.hr-base-selection-tag-wrapper` innerhalb des Selects.
- **Pflichtfeld-Stern & Error** — Beide bleiben `var(--danger)`. Pipeline-Name und Unterkonten-Auswahl sind Pflichtfelder.
- **`#copy` disabled State** — Der Copy-Button bleibt bis zur gültigen Auswahl disabled. `opacity: 0.5` bei unverändertem Wine-Hintergrund signalisiert den inaktiven Zustand.
