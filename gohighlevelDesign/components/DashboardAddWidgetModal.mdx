# Dashboard — Widget hinzufügen Modal — CSS Dokumentation

Das **„Widget hinzufügen"** Modal (`Section 87`) öffnet sich über den „+ Widget" Button auf der Opportunities-Seite. Es ermöglicht die Auswahl eines Dashboards und das Aktivieren/Deaktivieren von Widgets per Checkbox.

**Scope:** `.n-card.n-modal.hl-modal`

![Dashboard Add Widget Modal Screenshot](/dashboard-add-widget-modal-screenshot.png)

  border-radius: 8px !important;

.n-base-select-menu.n-select-menu .n-base-select-option--selected { color: var(--wine-2) !important; background-color: var(--wine-lt) !important; }

## Widget Karten & Checkboxen

Aktive Widget-Karten erhalten einen Wine-Border über `.border-primary-700`:

```css
.n-card.hl-modal .border-primary-700 {
  border-color: var(--wine) !important;
  border-radius: 8px !important;
}
```

### Checkbox — Wine Override
NaïveUI setzt `--n-color-checked` als Inline-Style — direkte `background-color` Überschreibung notwendig:

```css
.n-card.hl-modal .n-checkbox.n-checkbox--checked .n-checkbox-box-wrapper .n-checkbox-box {
  background-color: var(--wine) !important;
  border-color: var(--wine) !important;
}
.n-card.hl-modal .n-checkbox.n-checkbox--checked:hover .n-checkbox-box {
  background-color: var(--wine-2) !important;
}
/* Checkmark SVG weiß */
.n-card.hl-modal .n-checkbox.n-checkbox--checked .n-checkbox-box .n-checkbox-icon .check-icon path {
  fill: #ffffff !important;
}
```

## Besonderheiten

- **Checkbox Inline-Style Override** — NaïveUI setzt `--n-color-checked` direkt als Inline-Style. CSS-Variablen greifen nicht — `background-color` direkt auf `.n-checkbox-box` ist der einzige zuverlässige Override.
- **Widget Selector Hintergrund** — GHL nutzt `var(--wine-pale)` für die dezente rosa Fläche.
- **Teleportiertes Dropdown** — `.n-base-select-menu.n-select-menu` wird zu `<body>` teleportiert. Der Action-Footer mit „Erstellen Dashboard" hat einen eigenen Border-Top und Link-Farbe.
- **Karussell-Buttons** — werden über ihre expliziten IDs gescopert (`-btn-scroll_left` / `-btn-scroll_right`).
