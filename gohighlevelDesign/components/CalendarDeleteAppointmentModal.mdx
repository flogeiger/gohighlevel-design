# 🗑️ Termin Löschen Modal — CSS Dokumentation

Diese Seite dokumentiert alle CSS-Sections für das "Delete Appointment" Bestätigungs-Modal (Section 80) im SalonQueen GHL Whitelabel. Es öffnet sich über den Trash-Button im View Details oder Edit Details Drawer und fordert eine Bestätigung vor dem unwiderruflichen Löschen.

/* ── Icon Container (Trash + Close nebeneinander) */
.n-card.n-modal.hl-modal:has(#confirmation-header-modal-close-btn) .hl-icon-container {

## 80.3 · Footer Buttons (Stornieren & Löschen)

"Stornieren" Ghost-Button und "Löschen" Danger-Primär-Button — bewusst **rot** statt Wine um die destruktive Aktion zu signalisieren.

```css
/* ── Footer Layout */
.n-card.n-modal.hl-modal:has(#confirmation-header-modal-close-btn) .hl-modal-footer-actions {
  display: flex !important;
  justify-content: flex-end !important;
  gap: 8px !important;
}

/* ── Stornieren Button */
#confirmation-footer-btn-negative-action {
  border-radius: 8px !important;
  transition: all 0.12s !important;
}
#confirmation-footer-btn-negative-action:hover {
  background: var(--wine-lt) !important;
}
#confirmation-footer-btn-negative-action .n-button__border {
  border-color: var(--line-hard) !important;
  border-radius: 8px !important;
}
#confirmation-footer-btn-negative-action:hover .n-button__border {
  border-color: var(--wine) !important;
}
#confirmation-footer-btn-negative-action .n-button__state-border {
  border-color: transparent !important;
}
#confirmation-footer-btn-negative-action .n-button__content { color: var(--ink-2) !important; }
#confirmation-footer-btn-negative-action:hover .n-button__content { color: var(--wine-2) !important; }

/* ── "Löschen" Danger-Button
   Achtung: NaïveUI setzt background-color inline → direkt überschreiben */
#confirmation-footer-btn-positive-action {
  background-color: var(--danger) !important;
  border: 1px solid var(--danger) !important;
  border-radius: 8px !important;
  transition: all 0.12s !important;
}
#confirmation-footer-btn-positive-action:hover {
  background-color: #B42318 !important;
  border-color: #B42318 !important;
  transform: translateY(-1px) !important;
}
#confirmation-footer-btn-positive-action .n-button__content { color: var(--surface) !important; }
#confirmation-footer-btn-positive-action .n-button__border {
  border-color: var(--danger) !important;
  border-radius: 8px !important;
}
#confirmation-footer-btn-positive-action .n-button__state-border { border-color: transparent !important; }
```

---

> **Hinweis:** Der Modal-Scope läuft über `:has(#confirmation-header-modal-close-btn)` — dieselbe Strategie wie beim Consent Modal (Section 78). Der "Löschen"-Button verwendet bewusst `var(--danger)` statt Wine — einer der wenigen Fälle im System wo Rot statt Wine als Primärfarbe eingesetzt wird, um die Irreversibilität der Aktion visuell zu kommunizieren. Hover-Farbe `#B42318` ist ein dunkleres Danger-Rot (hardcoded, kein Token).
