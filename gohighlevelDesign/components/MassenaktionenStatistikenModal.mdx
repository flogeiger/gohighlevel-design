# Massenaktionen Statistiken Modal — CSS Dokumentation

Das **„Statistiken"** Modal (`Section 95`) öffnet sich über das Balkendiagramm-Icon (`⊟`) in einer Zeile der Massenaktionen-Seite. Es zeigt Statistik-Karten, gefilterte Tabs (Alle / Erfolg / Fehler), eine Detailtabelle und einen Download-Button.

**Scope:** `#bulk-action-statistics-modal`

![Massenaktionen Statistiken Modal Screenshot](/massenaktionen-statistiken-modal-screenshot.png)

---

## Betroffene Selektoren & Struktur

| Element | Selektor |
|---|---|
| Modal Shell | `#bulk-action-statistics-modal` |
| Close Button | `#hr-modal__close-button` |
| Stats Cards | `.general-stats` |

| Tabelle | `#stats-table` / `#stats-table-wrapper` |

## Stats Cards (`.general-stats`)

Die drei Karten (Alle / Erfolg / Fehler) haben einen Wine-lt Hintergrund. Die Prozentzahlen (weiß/grün/gelb) sind semantische Status-Farben und werden bewusst **nicht** überschrieben:

```css
#bulk-action-statistics-modal .general-stats {
  background-color: var(--wine-lt) !important;
  border: 1px solid var(--line-hard) !important;
  border-radius: 10px !important;
}
#bulk-action-statistics-modal .stat-heading       { color: var(--ink-3) !important; font-weight: 600 !important; }
#bulk-action-statistics-modal .general-stat-count { color: var(--ink) !important; font-weight: 700 !important; }
```

## Besonderheiten

- **Statistik-Prozentzahlen bleiben semantisch** — Die farbigen Prozentwerte in den Stats-Cards (weiß = neutral, grün = Erfolg, gelb/orange = Fehler) sind GHL-gerenderte Inline-Styles mit semantischer Bedeutung. Diese werden bewusst nicht überschrieben.
- **Tabs nutzen `--n-bar-color`** — Der aktive Tab-Indikator läuft über `.hr-tabs-bar`. Sowohl CSS-Variable als auch direktes `background-color` werden gesetzt für maximale Kompatibilität.
- **Status-Badge „Success"** bleibt grün — gleiche Logik wie Section 93.
- **Download Button** — Gleicher direkter `background-color` Override wie bei Primary-Buttons in Section 88–92.
