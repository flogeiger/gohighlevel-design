# Liste Anpassen Drawer — CSS Dokumentation

Diese Seite dokumentiert alle CSS-Sections für `#calendar-advanced-filter-drawer` im SalonQueen GHL Whitelabel. Der Drawer öffnet sich in der Termin-Listenansicht über den Button "Customize List" / "Liste anpassen".

## 73.1 · Drawer Shell & Header

Der Drawer-Container mit linker Border, Header-Hintergrund und Titel.

```css
/* ── Drawer Body */
#calendar-advanced-filter-drawer .n-drawer-content {
  background: var(--surface) !important;
  border-left: 1px solid var(--line-hard) !important;
}

/* ── Header */
#calendar-advanced-filter-drawer .n-drawer-header {
  background: var(--surface) !important;
  border-bottom: 1px solid var(--line-hard) !important;
}
#calendar-advanced-filter-drawer .hl-drawer-title {
  font-size: 16px !important;
  font-weight: 800 !important;
  letter-spacing: -0.03em !important;
  color: var(--ink) !important;
}

/* ── Body */
#calendar-advanced-filter-drawer .n-drawer-body {
  background: var(--surface) !important;
}
```

## 73.5 · Footer Buttons

Footer mit "Änderungen verwerfen" (Ghost) und "Als neu speichern" (Wine-Primär).

```css
/* ── Footer */
#calendar-advanced-filter-drawer .n-drawer-footer {
  background: var(--bg) !important;
  border-top: 1px solid var(--line-hard) !important;
}

/* ── "Änderungen verwerfen" Button */
#discard-changes {
  border-radius: 8px !important;
  --n-border: 1px solid var(--line-hard) !important;
  --n-border-radius: 8px !important;
}
#discard-changes .n-button__border {
  border-color: var(--line-hard) !important;
  border-radius: 8px !important;
}
#discard-changes .n-button__state-border { border-color: transparent !important; }
#discard-changes .n-button__content { color: var(--ink-2) !important; }
#discard-changes:not([disabled]):hover {
  background: var(--wine-lt) !important;
}
#discard-changes:not([disabled]):hover .n-button__border {
  border-color: var(--wine) !important;
}
#discard-changes:not([disabled]):hover .n-button__content {
  color: var(--wine-2) !important;
}

/* ── "Als neu speichern" Button
   Achtung: Das Blau kommt von bg-primary-600 auf einem inneren div,
   nicht vom Button selbst — muss separat überschrieben werden! */
#btn-save-smart-list {
  background-color: var(--wine) !important;
  border: 1px solid var(--wine) !important;
  border-radius: 8px !important;
  box-shadow: 0 2px 8px var(--wine-glow) !important;
  transition: transform 0.12s, box-shadow 0.12s !important;
}
#btn-save-smart-list:hover {
  background-color: var(--wine-2) !important;
  border-color: var(--wine-2) !important;
  transform: translateY(-1px) !important;
  box-shadow: 0 4px 14px var(--wine-glow) !important;
}
/* Inneres bg-primary-600 div deaktivieren */
#btn-save-smart-list .bg-primary-600 {
  background-color: transparent !important;
}
#btn-save-smart-list .n-button__content { color: var(--surface) !important; }
#btn-save-smart-list .hl-text-sm-medium {
  font-size: 12px !important;
  font-weight: 700 !important;
  color: var(--surface) !important;
}
#btn-save-smart-list svg { color: var(--surface) !important; }
#btn-save-smart-list .n-button__border {
  border-color: var(--wine) !important;
  border-radius: 8px !important;
}
#btn-save-smart-list .n-button__state-border { border-color: transparent !important; }
```

---

> **Hinweis:** Der `#btn-save-smart-list` Button hat eine Besonderheit: GHL rendert ein inneres `div.bg-primary-600` welches das Blau injiziert — unabhängig vom Button-Hintergrund selbst. Daher wird `background-color: transparent` auf `.bg-primary-600` gesetzt und die Farbe direkt auf den Button-Wrapper angewendet. Das `#discard-changes` nutzt `:not([disabled])` um den deaktivierten Zustand visuell zu erhalten.
