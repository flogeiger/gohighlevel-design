# Import Invoices

Der **Import Invoices**-Flow (`#importInvoices`) ist ein 4-Step-Wizard (Upload → Felder Map → Steuern Map → Importieren) mit Fixed Header, Fixed Footer und einem NaïveUI-Stepper. Step 1 zeigt eine Info-Box mit Anweisungen und eine Drag-&-Drop-Upload-Zone für CSV-Dateien. Ein Abbrechen-Modal bestätigt den Abbruch des Imports.

## Besonderheiten

**`:has()`-Selektor für Modal-Scope:** Das Abbrechen-Modal hat keine eigene Root-ID — es wird über `.hl-modal:has(#cancel-import-header-modal-close-btn)` gescoped. Das ist das einzige Beispiel im Payments-Bereich, wo `:has()` als Modal-Anker verwendet wird (sonst wird `:has()` hauptsächlich für dynamische ID-Prefixe genutzt).

**Escaped Utility-Klassen mit `.\!text-primary-500`:** Die CSV-Download-Links und Steuer-Links verwenden Tailwind's forced-important Präfix — in CSS muss der `!` als `\!` escaped werden. Alle drei Varianten (`a.\!text-primary-500`, `.\!text-primary-500`, `.text-primary-500`) werden abgedeckt, da GHL unterschiedliche Render-Pfade nutzt.

**NaïveUI Stepper mit `--n-indicator-*`-Variablen:** Der Stepper nutzt ein anderes Variablen-Schema als die meisten anderen NaïveUI-Komponenten — `--n-indicator-color` statt `--n-color`, `--n-header-text-color` statt `--n-text-color`. Beide States (process, wait) müssen explizit gesetzt werden.

**`#cancel-btn` ohne State-Border-Fix:** Der Cancel-Button in der Footer-Leiste ist ein reiner Text-Button ohne Border-Box — er braucht keinen `border-width: 0`-Fix, da er von Haus aus keinen `n-button__state-border` rendert.
