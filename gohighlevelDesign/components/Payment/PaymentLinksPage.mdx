# Payment Links

Die **Payment Links**-Seite (`#paymentlinksDashboardApp`) listet alle erstellten Zahlungslinks mit URL, Status, Preis und Erstellungsdatum. Sie enthält Datepicker, Suchfeld, Filter-Popover, eine NaïveUI DataTable mit Pagination sowie zwei Primary-Buttons (Header + Empty State).

Diese Section enthält außerdem den **Global Fix v2** für Pagination und Per-Page-Select — ein `html body`-geprefixter Override der NaïveUI-Variablen, der auf alle Tabellen-Footer im gesamten Projekt wirkt.

## 114.5 – Global Fix: Pagination & Per-Page Select

Dieser Block wirkt **global auf alle Tabellen-Footer** im Projekt (`html body .ghl-table-footer`). Der `html body`-Präfix ist nötig, um die NaïveUI-internen CSS-Variablen mit ausreichender Spezifität zu überschreiben.

```css

html body .ghl-table-footer .n-base-selection {
  --n-border-hover:      1px solid var(--wine) !important;
  --n-border-active:     1px solid var(--wine) !important;
  --n-border-focus:      1px solid var(--wine) !important;
  --n-box-shadow-active: 0 0 0 3px var(--wine-a20) !important;
  --n-box-shadow-focus:  0 0 0 3px var(--wine-a20) !important;
  --n-caret-color:       var(--wine) !important;
  --n-loading-color:     var(--wine) !important;
}

/* Previous / Next Buttons → wine hover */

  --n-border-hover:         1px solid var(--wine) !important;
  --n-border-pressed:       1px solid var(--wine) !important;
```

## Besonderheiten

**Doppel-Border-Fix für `.hl-table-filter-btn`:** NaïveUI rendert Buttons mit zwei überlagerten Border-Elementen — dem nativen `border` auf dem Button-Element selbst und `.n-button__border` als Pseudo-Overlay. Der Fix setzt `border-width: 0` auf dem Button-Root und definiert die sichtbare Border ausschließlich über `.n-button__border`. Dieser Fix gilt gleichzeitig für `#paymentlinksDashboardApp`, `#OrdersListPage` und `#SubscriptionsListPage` in einem Selektor-Block.

**Global Pagination Fix mit `html body`-Präfix:** NaïveUI setzt Pagination-Variablen mit hoher Spezifität direkt auf den Komponenten-Root. Der einzige zuverlässige Override ohne `!important`-Kaskaden-Konflikte ist der `html body`-Präfix, der Spezifität (0,0,2) erzeugt und NaïveUIs (0,0,1) schlägt. Dieser Block ist **projektübergreifend** — er wirkt auf jede Seite mit `.ghl-table-footer`.

**Zwei Primary-Buttons:** Header-Button (`#payment-links-header-btn-primary`) und Empty-State-Button (`#payment_links_products__empty-btn-positive-action`) sind funktional identisch, aber über unterschiedliche IDs angesteuert — der Empty-State-Button verschwindet, sobald Einträge vorhanden sind.
