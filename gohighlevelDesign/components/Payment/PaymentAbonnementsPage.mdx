# Abonnements

Die **Abonnements**-Seite (`#SubscriptionsListPage`) listet alle Kundenabonnements, die über Bestellformulare erstellt wurden. Sie bietet Datepicker, Suchfeld, Filter-Popover, CSV-Export und einen Primary-Button zum Hinzufügen neuer Abonnements.

<img src="/payment-abonnements-page.png" alt="Abonnements" style={{ width: '100%', borderRadius: '8px', marginBottom: '1.5rem' }} />

---

## Struktur & Root-Selektoren

| Bereich | Selektor |
|---|---|
| Root | `#SubscriptionsListPage` |
| „Abonnement hinzufügen"-Button | `#subscriptions__header-btn-primary` |
| Datepicker | `#subscriptions-date-range` |
| Suchfeld | `#hl-table-subscriptions-filter-text-search` |
| Filter-Button | `#SubscriptionsListPage .hl-table-filter-btn` |

| Empty State | `#SubscriptionsListPage .hl-empty-icon-container` |

## Besonderheiten

**`#table-export-csd` hier mit Parent-Scope:** Im Gegensatz zu anderen Seiten wird `#table-export-csd` hier über `#SubscriptionsListPage #table-export-csd` gescoped — verhindert Konflikte mit der gleichnamigen ID auf der Bestellungen- und Rechnungen-Seite, sofern GHL mehrere Seiten gleichzeitig im DOM hält.

**Filter-Popover ohne Root-Scope:** `#hl-table-subscriptions-filter-clear / -apply` sind IDs und daher global eindeutig — kein zusätzlicher Scope nötig.
