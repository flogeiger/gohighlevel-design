# Gift Cards

Die **Gift Cards**-Seite (`#GiftCards`) ist ein vollständig mit **Highrise UI** (`hr-*`-Klassen) gebautes 4-Step-Formular zur Erstellung von Geschenkkarten. Die Listen-Ansicht zeigt einen Empty State mit Illustration und zwei Primary-Buttons. Der **Gift Card Editor** (`#CreateGiftCards`) führt durch vier Schritte: Basic Info → Customize Card → Set Values → Review Card.

## Besonderheiten

**4-Step Progress Stepper mit Highrise-Klassen:** Der Fortschrittsanzeiger nutzt `.hr-progress-step--current` und `.hr-progress-step--complete` — zwei separate State-Klassen. Der aktive Step erhält `var(--wine)` als vollen Hintergrund, abgeschlossene Steps `var(--wine-lt)` mit wine-Border. Die Verbindungslinie `.hr-progress-step__line-bar` wird für beide auf wine gesetzt.

**`#save-continue-button` mit Editor-Scope:** Im Gegensatz zur Coupons-Seite (Section 120b), wo `#save-continue-button` global verwendet wird, ist der Button hier über `#CreateGiftCards #save-continue-button` gescoped — verhindert Konflikte.

**Edit-Buttons mit wine-Border (kein Fill):** Die Stift-Icons in der Review Card (Step 4) sind als outline-wine gestylt — Border wine, Hintergrund transparent, fill-hover auf wine-lt. Abweichendes Pattern zu den meisten outline-Buttons im Projekt, die `--line-hard` als Default-Border nutzen.

**`text-purple-600` auf wine gemappt:** Der „Write Using AI"-Link nutzt eine Tailwind-Violett-Klasse. Da kein semantischer Selektor verfügbar ist, wird `.text-purple-600` direkt auf `var(--wine-2)` gemappt — technisch korrekt, da AI-Features im SalonQueen-Kontext ebenfalls wine-Farbe erhalten.
