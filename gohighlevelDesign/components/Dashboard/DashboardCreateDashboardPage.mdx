# Neues Dashboard erstellen — CSS Dokumentation

Die **„Neues Dashboard"** Auswahl-Seite (`Section 106`) öffnet sich über „+ Dashboard hinzufügen" im Dashboard-Switcher. Sie präsentiert drei Optionskarten zur Erstellungsmethode.

## Option Cards (`.create-dashboard-ui .hl-card`)

Die drei Karten (Leer / Vorlagenbibliothek / Klonen) erhalten bei Hover einen Wine-Border und -Hintergrund. Die mittlere Karte (aktuell ausgewählt) zeigt bereits einen wine-lt Hintergrund:

```css
.create-dashboard-ui .hl-card {
  background-color: var(--surface) !important;
  border: 2px solid var(--line-hard) !important;
  border-radius: 12px !important;
  transition: border-color 0.15s, background-color 0.15s !important;
}
.create-dashboard-ui .hl-card:hover {
  border-color: var(--wine) !important;
  background-color: var(--wine-lt) !important;
}
/* Card-Titel */
.create-dashboard-ui .hl-card .text-gray-900 { color: var(--ink) !important; }
/* Card-Beschreibung */
.create-dashboard-ui .hl-card .text-gray-600 { color: var(--ink-3) !important; }
```

## Besonderheiten

- **Aktive Karte (mittlere)** — GHL hebt die zuletzt geklickte/empfohlene Karte mit einem rosa Border hervor. Der `border: 2px solid var(--wine)` Override greift für diesen Zustand automatisch via Hover-Pattern. Für einen dedizierten „aktiv"-State kann zusätzlich `.hl-card.active` oder `.hl-card[aria-selected="true"]` gescopert werden.
- **Illustrationen** — Die Inline-SVG-Illustrationen in den Karten werden nicht überschrieben — sie sind dekorative Elemente ohne Branding-Relevanz.
- **`Zurück`-Button** — Nutzt `color: var(--wine)` im Default-State (nicht erst bei Hover) — signalisiert als Link-Button statt als regulärer Action-Button.
