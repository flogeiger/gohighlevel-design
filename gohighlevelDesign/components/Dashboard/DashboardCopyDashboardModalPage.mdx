# Dashboard kopieren Modal — CSS Dokumentation

Das **„Kopieren in ein anderes Konto"** Modal (`Section 103`) öffnet sich über das Kebab-Menü eines Dashboards. Es ermöglicht das Kopieren eines Dashboards in ein anderes Konto mit neuem Namen und Konto-Auswahl.

**Scope:** `body .hl-modal:has(#location-dashboard_modal-header--location_dashboard-modal-duplicate_dashboard-modal-close-btn)`

![Dashboard Kopieren Modal Screenshot](/dashboard-copy-modal-screenshot.png)

---

## Besonderheiten

- **`.icon.icon-custom`** — Dieses Modal verwendet `.icon-custom` statt `.icon-success` (Section 102). Gleicher Fix: `background-color: transparent` auf dem Container, SVG direkt auf wine.
- **`#dashboard_name`** — Kurze, generische ID. Da dieses Modal nie gleichzeitig mit anderen Modals offen ist, gibt es keinen DOM-Konflikt.
- **Ähnlichkeit zu Section 102** — Struktur und Pattern sind nahezu identisch mit dem Klonen-Modal — der einzige Unterschied ist das zusätzliche Konto-Select (`#location-dropdown`) und die abweichenden Button-IDs.
