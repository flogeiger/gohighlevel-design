# Berechtigungen verwalten Modal — CSS Dokumentation

Das **„Berechtigungen verwalten"** Modal (`Section 101`) öffnet sich über das Kebab-Menü eines Dashboards. Es ermöglicht das Festlegen von Zugriffsrechten (Privat / Agenturnutzer / Kontoadministrator / Konto-Benutzer) sowie das Aktivieren des Privat-Modus via Toggle.

**Scope:** `body .hl-modal:has(#location-dashboard_modal-header--manage-permissions-modal-close-btn)`

![Dashboard Berechtigungen Modal Screenshot](/dashboard-permissions-modal-screenshot.png)

## Besonderheiten

- **Modal Scope via `body` + `:has()`** — Das Modal ist zu `<body>` teleportiert. Der kombinierte Selektor `body .hl-modal:has(#...close-btn)` ist notwendig um maximale Spezifität gegen GHL-eigene Styles zu erreichen.
- **Toggle Switch** — `--n-rail-color-active` steuert die aktive Farbe des Sliders. Kein direktes `background-color` nötig — NaïveUI-Var greift hier zuverlässig.
- **`bg-gray-50` Card** — GHL setzt Tailwind-Klasse direkt am Container. Direkter Override auf `background-color` notwendig — `var(--wine-lt)` als dezenter Hintergrund für die Privat-Modus-Karte.
- **Info Icon** — Das Warn-Icon neben dem Hinweistext wird via `svg` Selektor auf Wine gesetzt. `stroke` statt `fill` da das Icon Outline-Style nutzt.
- **Eigentümer-Zeile** — Hat keinen eigenen Selektor/ID — wird über Tailwind-Klassen (`.hl-text-sm-normal`, `.text-gray-500`) gestylt.
