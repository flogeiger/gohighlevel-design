# Dashboard-Zeitzone verwalten Modal — CSS Dokumentation

Das **„Dashboard-Zeitzone verwalten"** Modal (`Section 105`) öffnet sich über das Kebab-Menü eines Dashboards. Es ermöglicht die Auswahl der bevorzugten Zeitzone für alle Dashboard-Widgets.

**Scope:** `body .hl-modal:has(#location-dashboard_modal-header--location_dashboard-modal-manage_timezone-modal-close-btn)`

![Dashboard Zeitzone Modal Screenshot](/dashboard-timezone-modal-screenshot.png)

---

## Betroffene Selektoren & Struktur

| Element | Selektor |
|---|---|
| Modal Shell | `body .hl-modal:has(#...manage_timezone-modal-close-btn)` |
| Close Button | `#location-dashboard_modal-header--location_dashboard-modal-manage_timezone-modal-close-btn` |

## Besonderheiten

- **`.icon.icon-primary`** — Dieses Modal verwendet `.icon-primary` als Icon-Variante. Gleicher Fix wie Section 102/103: `background-color: transparent` auf dem Container, SVG direkt auf wine.
- **`.bg-gray-100` Info-Box** — Tailwind-Klasse direkt am Container. Der wine-lt Hintergrund signalisiert einen informativen (nicht warnenden) Hinweis — keine danger-Farbe notwendig.
- **Gleiche Struktur wie Section 103** — Heading, Description, Select, Info-Box und Footer folgen exakt demselben Pattern wie das „Kopieren"-Modal.
