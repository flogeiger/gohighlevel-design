# Conversations – Konversationen (Section 108)

Die Konversationen-Seite ist das zentrale Kommunikations-Hub in GHL. Sie besteht aus drei Spalten: der **Konversationsliste** (links), dem **Nachrichtenbereich** (Mitte) mit Compose-Box, sowie dem **Kontakt-Panel** (rechts). Zusätzlich existiert ein schmales **Mini-Panel** ganz rechts mit Icon-Schnellzugriff.

![Conversations Page Screenshot](./conversations-page-screenshot.png)

## Besonderheiten

**`data-v-f0d4cc20-s` (DND-Sektion):** Dieser Selektor ist ein Vue-Scoped-Attribute und kann sich nach GHL-Deployments ändern. Bei Bruch → DOM inspizieren und neues `data-v-*` Attribut ermitteln.

**`[style*="56, 160"]` (aktiver Tab):** GHL setzt den aktiven Tab-Underline per Inline-Style (`color: rgb(56, 160, ...)`). Der Attribut-Selektor `[style*="56, 160"]` fangt das ab, ist aber fragil. Alternativ: `[aria-current="page"]`.

**Send + Schedule-Later:** Beide Buttons bilden eine zusammengesetzte Gruppe — `#send-sms` hat `border-radius: 8px 0 0 8px`, `#schedule-later` hat `border-radius: 0 8px 8px 0`.

**Custom Checkboxen:** `appearance: none` entfernt das native Browser-Styling vollständig. Das Häkchen wird als `::after`-Pseudo-Element mit `border-top: none; border-left: none; transform: rotate(45deg)` gezeichnet. Gleiches Muster wird in Section 108.9 (Activity Filter) und Section 108.11 (DND) verwendet.

**Channel-Tab hover override:** GHL setzt den blauen Hover-Streifen über Bootstrap `.nav-tabs` — es braucht `border-color: transparent transparent var(--wine)` (Shorthand für oben/seiten/unten) um nur den unteren Border zu überschreiben.
