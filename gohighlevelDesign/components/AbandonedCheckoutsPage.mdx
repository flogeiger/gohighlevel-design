# Abgebrochene Checkouts

Die **Abandoned Checkouts**-Seite (`#abandonedCheckouts`) listet alle unvollständigen Online-Checkouts unter „Bestellungen". Die Seite enthält ausschließlich Seitentitel, Beschreibung und eine NaïveUI DataTable mit Empty State — keine Filter-Buttons, kein Suchfeld, kein Primary-Button.

## Besonderheiten

**Minimale Seite ohne Filter-UI:** Abgebrochene Checkouts ist die einzige Payments-Listenseite ohne Suchfeld, Datepicker oder Filter-Button. Das CSS beschränkt sich auf BG, DataTable-Variablen und Empty State.

**Spalte „Status der Wiederherstellung":** Die Tabelle hat eine ungewöhnlich lange Spaltenüberschrift, die im Screenshot umgebrochen wird — kein CSS-Eingriff nötig, da GHL die Breite automatisch verwaltet.
