## 63.3 · "Add New" Button

Primärer Button im Empty State (und in der Verbindungsliste). Verwendet `::before` Overlay weil NaïveUI den `background` via JS überschreibt.

```css
#newConnection {
  position: relative !important;
  overflow: hidden !important;
  border-radius: 8px !important;
  font-weight: 700 !important;
  --n-border-radius: 8px !important;
}

/* ── Hintergrund via ::before (schlägt NaïveUI JS inline style) */
#newConnection::before {
  content: "" !important;
  position: absolute !important;
  inset: 0 !important;
  background: var(--wine) !important;
  z-index: 0 !important;
  pointer-events: none !important;
}
#newConnection:hover::before {
  background: var(--wine-2) !important;
}

/* ── Text & Borders */
#newConnection .n-button__content {
  position: relative !important;
  z-index: 1 !important;
  color: var(--surface) !important;
}
#newConnection .n-button__border {
  border-color: var(--wine) !important;
  border-radius: 8px !important;
}
#newConnection .n-button__state-border {
  border-color: transparent !important;
}
```

## 63.4 · Google Organic Booking Tab

Info-Box, Toggle Switch und Form-Selects im "Google Organic Booking" Tab.

```css
/* ── Info Box */

}

/* ── Form Selects */

#select-calendars-as-entity-service .n-base-selection {
  border-radius: 8px !important;
  --n-border-radius: 8px !important;

}
#calendar-group-select .n-base-selection__border,

}

/* ── Form Labels */

  font-weight: 800 !important;
  text-transform: uppercase !important;
  letter-spacing: 0.08em !important;
  color: var(--ink-3) !important;
}
```

---

> **Hinweis:** Der `#newConnection` Button verwendet ein `::before` Pseudo-Element als Hintergrund-Overlay, da NaïveUI den `background`-Wert via JavaScript als Inline-Style setzt und damit normale CSS-Overrides überschreibt. Die `z-index` Schichtung stellt sicher, dass der Button-Text weiterhin sichtbar bleibt.
