# Launchpad Modals — CSS Dokumentation

Diese Seite dokumentiert alle Modals (`Section 97`) die sich über die Aktions-Buttons der Launchpad-Seite öffnen. Alle vier Modals teilen eine gemeinsame CSS-Basis.

| Modal | Trigger | Scope |
|---|---|---|
| **Mobile App** | „Link senden" | `.mobile-container` |
| **Facebook Hinweis** | „Verbinden" (Facebook) | `.gmb-container` / `.fb-container` |
| **Chat-Widget** | „Verbinden" (Webchat) | `#chat-widget-modal` |
| **Benutzer hinzufügen** | „Hinzufügen" | `.modal-container` |

---

![Mobile App Modal Screenshot](/launchpad-mobile-modal-screenshot.png)

## Gemeinsame Regeln

Alle vier Modals teilen die folgenden globalen Pattern:

```css
/* Shell */
.gmb-container, .mobile-container,
#chat-widget-modal, .modal-container {
  background-color: var(--surface) !important;
  border: 1px solid var(--line-hard) !important;
  border-radius: 12px !important;
}

/* Form Labels */
.fb-container label, .mobile-container label,
.modal-container label, .card label {
  color: var(--ink) !important;
  font-weight: 500 !important;
}

/* Alle Primary Buttons */
.btn.btn-primary, .launchpad-filled-button, .launchpad-blue-btn {
  background-color: var(--wine) !important;
  border: 1px solid var(--wine) !important;
  color: #ffffff !important;
  border-radius: 8px !important;
}
.btn.btn-primary:hover, .launchpad-filled-button:hover, .launchpad-blue-btn:hover {
  background-color: var(--wine-2) !important;
  border-color: var(--wine-2) !important;
}
```

## Besonderheiten

- **`.btn.btn-primary`** — GHL nutzt Bootstrap-Klassen für die Modal-Buttons. Kein NaïveUI — direktes `background-color` Override ohne `--n-*` Variablen.
- **`.hl-text-input` Focus-Ring** — GHL setzt Tailwind-Klassen wie `focus:ring-curious-blue-500` direkt im HTML. Fix: Tailwind CSS-Variablen (`--tw-ring-color`) direkt überschreiben.
- **Tag Input** (Benutzer-Modal) — `.tag-input` ist ein spezieller Multi-Email-Input. `focus-within` statt `:focus` da der eigentliche Input ein Kind-Element ist.
- **Facebook-Modal** — Das Info-Bild (Facebook-Berechtigungen Beispiel) wird nicht überschrieben — es ist ein externes Bild und hat keine CSS-Styling-Relevanz.
