# App-Marktplatz – Einstellungen (Section 113c)

Die Marketplace-Einstellungen (`Einstellungen → App-Marktplatz`) sind eine Agency-Level-Seite mit eigenem Root-Scope `#marketplace-main` — getrennt von `#marketplace-app` (Sections 113/126). Die Seite hat drei Tabs: **Marketplace Visibility**, **Manage App Access** (mit Toggle, Suchfeld, DataTable und Kategorien-Sidebar) und **App Usage Limits**. Besonderheit: GHL setzt auf `.ui-button.hr-button--tertiary-type` einen `--n-text-color: var(--primary-700)` Override per Stylesheet — dagegen braucht es ID-Spezifität (`#marketplace-main`).

## Besonderheiten

**`#marketplace-main` vs `#marketplace-app`:** Marketplace Settings hat einen eigenen Root-Scope (`#marketplace-main`) — getrennt von der normalen Marktplatz-Seite (`#marketplace-app`). Kein Scope-Overlap, kein Konflikt.

**Tertiary-Button GHL-Override-Problem:** GHL setzt `.ui-button.hr-button--tertiary-type { --n-text-color: var(--primary-700) }` mit Klassen-Spezifität. Da `#marketplace-main` eine ID ist (Spezifität: 1-0-0 vs. 0-2-0), gewinnt unser Override — plus direktes `color: var(--wine)` auf `:hover` als Sicherheitsnetz.

**Agency-Level Seite:** Diese Seite ist nur auf Agency-Ebene sichtbar (nicht in Sub-Accounts). Linke Navigation zeigt Agency-Items wie „Sub-Accounts", „Reselling", „SaaS Configurator".
