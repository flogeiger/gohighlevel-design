# Estimate Template Editor

Der **Estimate Template Editor** (`#estimatesTemplateApp`) ist die Vorlage-Variante des Invoice Editors — strukturell identisch mit zweigeteiltem Layout (links Konfiguration, rechts Live-Preview „ESTIMATE"), aber mit einem Prefix-Input (`#estimate-prefix-input`) statt Rechnungsnummer-Feldern und einem einzigen **„Save"-Button** (kein „Send"). Die Preview-Sektion zeigt einen Kostenvoranschlag mit Ablaufdatum.

## Besonderheiten

**`#editor-send-customer-save` als Save-Button:** Diese ID deutet auf einen ursprünglich kombinierten „Save & Send"-Button hin — im Estimate Template Editor fungiert er ausschließlich als „Save". Im Invoice Editor (Section 125) heißt der entsprechende Button `#invoice-editor-save`.

**`#btn-1` als Back-Button (innerhalb Root-Scope):** Die ID `#btn-1` ist global — hier wird sie über `#estimatesTemplateApp #btn-1` gescoped, um Konflikte mit dem Back-Button auf anderen Seiten zu vermeiden (Section 115 Payment Link Editor nutzt dieselbe ID ohne Scope).

**`#hl-enmpty__custom-actions-slot-button` — Tippfehler in der GHL-Codebase:** Die ID enthält „enmpty" statt „empty" — ein GHL-interner Tippfehler, der als-is übernommen werden muss. Der Selektor darf nicht korrigiert werden.

**Produkt-Tabellen-Header via Layout-Klassen:** Im Gegensatz zum Invoice Editor (`.columns`) nutzt der Estimate Template Editor die Layout-Klasse `.flex.pl-2.w-full.justify-evenly` als Tabellen-Header-Selektor — kein semantischer Klassenname verfügbar.
