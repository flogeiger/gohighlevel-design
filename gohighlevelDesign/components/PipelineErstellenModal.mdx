# Pipeline Erstellen Modal — CSS Dokumentation

Das **„Pipeline Erstellen"** Modal (`Section 90`) öffnet sich über den „+ Pipeline Erstellen" Button auf der Pipelines-Seite. Es ermöglicht das Anlegen einer neuen Pipeline mit Name und beliebig vielen Phasen.

**Scope:** `.hr-modal:has(#pipeline-name-input)`

![Pipeline Erstellen Modal Screenshot](/pipeline-erstellen-modal-screenshot.png)

---

## Betroffene Selektoren & Struktur

| Element | Selektor |
|---|---|
| Modal Shell | `.hr-modal:has(#pipeline-name-input)` |
| Pipeline-Name Input | `#pipeline-name-input` |
| Error Feedback | `.hr-form-item-feedback--error` |

## Besonderheiten

- **Modal Scope via `:has()`** — Das Modal hat keine eigene ID. Scope wird über `#pipeline-name-input` im Inhalt gesetzt — gleiches Pattern wie Section 83.
- **Error State bleibt `danger`** — Pflichtfeld-Stern, Fehlertext und roter Input-Border nutzen `var(--danger)`. Wine wird hier bewusst nicht eingesetzt.
- **Delete-Button nutzt `danger`** — Gleiche Logik wie Section 88: destruktive Aktionen erhalten `var(--danger)` on Hover, nicht Wine.
- **Checkboxen** — Zwei Checkboxen pro Zeile (Funnel-Diagramm + Phasenverteilung). Selbes Override-Pattern wie Section 84-B: direkte `background-color` auf `.n-checkbox-box`.
- **Drag Handle** — SVG `stroke` statt `fill`. Hover zeigt `var(--ink-2)` statt Wine — Drag-Handles sind keine primären Aktionen.
