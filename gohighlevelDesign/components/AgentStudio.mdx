# AI-Assistenten – Agent Studio (Section 121)

Das Agent Studio (`AI-Assistenten → Agent Studio`) nutzt die **Highrise Library** (`hr-` Prefix). Scope ist `.agent-directory-content-wrap`. Die Seite enthält eine Alert-Box, Sort-Button mit Dropdown, Suchfeld, DataTable mit Checkboxen und Pagination. Zusätzlich gibt es zwei Sub-Sections: **121b** (Neuer Ordner Modal, `#folder-modal`) und **121c** (Agent erstellen Dropdown, `#create-agent-dropdown`).

Besonderheit: Highrise nutzt `--primary-600` CSS-Variablen direkt im Komponentenrendering — diese werden am Root-Scope überschrieben statt per Klassen-Override.

## Besonderheiten

**`--primary-600` auf Root-Scope:** Highrise rendert Button-Farben direkt via `var(--primary-600)` ohne über Klassen-Overrides erreichbar zu sein. Die Lösung ist, `--primary-600` auf `.agent-directory-content-wrap` selbst zu überschreiben — alle Highrise-Komponenten darunter erben den neuen Wert.

**Floating Dropdowns (`#sort-dropdown`, `#create-agent-dropdown`):** Beide werden außerhalb des `.agent-directory-content-wrap`-Scopes im DOM gemountet. Sie müssen global via ID targetiert werden — kein Scope-Präfix möglich.

**`data-v-23397495` Pagination:** Der aktive Pagination-Button hat ein Vue-Scoped-Attribut. Fragil bei GHL-Deployments — alternativ: `.hr-pagination-item__active button` (ohne `data-v`), falls der `data-v`-Wert sich ändert.
